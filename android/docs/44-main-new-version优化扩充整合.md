# main(new version) 优化扩充版本整合

目标工程为 `spotlight2026-main`，来源为同级 `spotlight2026-main(new version)`。本次以旧版公共基线 `spotlight2026-main(new)` 做三方比较，只合入来源版本的新增与修改，并将相同功能同步到独立 Android 工程；没有直接覆盖 main，也没有复制 `.godot`、真实存档或平台专用工程配置。

合并前快照保存在 `spotlight2026-main/_local/new-version-merge-before-20261020`。

## 合入内容

- 怪物完整意图预览、意图存档与行动序号显示。
- 主怪保持原始尺寸，最多两只召唤物使用左右固定战位、独立短血条和缩小意图；满员召唤失败不会错误刷新意图。
- 第四层 `summit-v1`、第四层商店和最终 Boss 23。最终 Boss 为 305 生命、每回合三动，半血进入第二阶段并启用逆行土星机制。
- 前三层 Boss 完成后进入下一层，第四层领奖完成后进入通关结算；旧三层存档仍按原三层终点恢复，不会被强行扩为四层。
- 地图缓存、结点场景后台预加载、已知结点快速传送、地区名称首次进入显示和固定测试地图。
- 扩充随机事件、事件战斗衔接、伤害试炼和素材升级选择界面。
- Wwise 音频桥接、事件 ID、SoundBank、启动页和设置界面；战斗状态机重新挂载时使用信号防重连接。

## main 状态保留

- 解剖者每次攻击 2 点、每回合三次行动。
- 初始抽牌 6、每回合抽牌 3、牌位 3。
- 初始牌组仍为 3 张狮子之血、3 张灰吹银、2 张盾与矛；新游戏没有典籍残片。
- 保留 70 张正式卡图、卡图填满卡框、事件队列与规则引擎、奖励、附魔、商店、图鉴和结算记录。
- 不恢复已删除的成就与解锁机制。
- Android 保留独立存档、点击寻路、再次点击交互、长按悬停、触屏布局、安全区和地图设置按钮。

## 已知限制

当前 Wwise SoundBank 可初始化并加载，但来源版本的媒体库仍缺少部分事件媒体，运行时会出现 `Selected media ... not available`。这不影响玩法逻辑和上述测试结果，需要在 Wwise 音频工程中补全媒体后重新生成 SoundBank 才能彻底消除。
