# 事件与卡牌文字布局调整

## 随机事件

- 场景：`ui/events/random_event_scene.tscn`。
- `EventBackground`：全屏背景，保持比例覆盖屏幕；不再创建外框和全屏暗罩。
- `OptionsColumn`：右侧选项区域。默认锚点左 `0.66`、右 `0.96`、上 `0.10`、下 `0.90`。在 Godot 2D 编辑器调整 Layout 的 Anchors / Offsets 可移动整列、修改宽高。
- `EventTitle`、`EventStatus`：事件标题、状态和结果说明，文字描边用于保证背景图上的可读性。
- `OptionsColumn/OptionsScroll/Options`：动态按钮容器，超长列表可滚动。
- 逻辑：`ui/events/random_event_scene.gd`。根节点检查器导出 `option_button_min_size`（默认最小高度 76）、`option_button_font_size`（23）、`option_button_spacing`（14）。按钮宽度跟随整列宽度，长选项自动换行。
- 按钮在 `_button()` 中动态生成；不要在运行中的临时按钮上修改后期望保存到场景。选择根节点修改导出属性，或调整 OptionsColumn。残片说明与其选择按钮改为上下排列，适应窄列。

事件内容、奖励、种子、存档、选择限制和完成后返回流程不变。

## 卡牌文字

- 共用场景：`ui/components/card/card_view.tscn`，同时用于手牌、出牌区、奖励选择等。
- `卡名` / `效果文本`：在编辑器中调锚点和偏移，决定文字区域的位置与大小。效果框底边改为 `0.94`，避免正文压到底图下方的装饰边角。
- 共用排版：`ui/components/card/card_view.gd` 的 `_refresh_compact_text()`。根据场景里实际文本框的尺寸、字体字宽与行高换行，不再使用写死的宽高。
- 最大局部字号：`LOCAL_TITLE_PX = 56`，`LOCAL_BODY_PX = 49`。以 480×818 卡内坐标计，画面实际字号还会随卡牌整体缩放。
- 根节点检查器导出的最小局部字号：`compact_title_min_size = 28`、`compact_body_min_size = 26`。短文本保留原字号，长文本在上下限间适配；极长正文仍放不下时才省略，原始资料与效果不变。
- `TEXT_SAFETY_PADDING = Vector2(8, 8)`：给描边、阴影预留空间。
- 适配结果按文案、文本框和字体参数缓存（上限 512 项）；重复刷新或悬停缩放不反复测字。
- `ui/components/card_text.gd`：按真实字宽换行，保留显式换行；修正行末标点可能被交换到前一字符前的问题。

悬停只放大整张牌，文字不因悬停重新排版。所有几何仍在 `.tscn`，排版脚本不重写节点位置/尺寸，便于手动调整。

## 验证入口

- `tests/card_text_bounds_selftest.tscn`：全部正式卡在手牌、选择、悬停比例下的文字边界、换行保序、显式换行和超长文案兜底；不写玩家存档。
- `tests/random_event_flow_selftest.tscn`：真实地图进入事件、无边框全屏布局、右侧选项、保存冷恢复与完成返回；存档只写测试目录。
