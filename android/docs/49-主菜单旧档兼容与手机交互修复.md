# 主菜单旧档兼容、奖励规则与手机交互修复

日期：2026-10-21。

## 本轮变更

- 普通、精英和 BOSS 战斗胜利奖励各列出 2 个万灵药；事件、离店、宝箱、残堆不再额外赠药。旧档已经领取的万灵药不扣回；未领取的旧宝箱记录过滤额外药品，不重抽主奖励。
- 同一 Godot 版本、同一完整源码提交的 Steam/official 构建允许恢复同一随机快照；其他版本、提交、协议与内容版本继续严格校验。地图入口也使用规范化快照比较，不重装全局随机上下文或作废已有随机流。
- 读取错误的存档不再阻止退出游戏，退出时不覆盖错误原文件。
- Android 地图只允许结点中心半径 28 个视口逻辑像素的小范围选择结点，不再用整个结点占地作点击范围。名称提示只保留中心 64×28 的区域，无额外外扩。其他点击继续按真实高程拾取地块并寻路；碰撞和 E 交互距离不变。
- Android 战斗隐藏旧独立背包大底板，保留全部物品格自己的边框。该装饰层不承担输入或背包数据，移除后不会遮住血条与头像。
- 手机两项适配按用户明确指定仅作用于 Android；PC 布局、鼠标移动保持不变。其余公共逻辑同步两端，并核对文件哈希。

## 关键文件

- `android/ui/world_map/flat_2d/map_demo.gd`：`MOBILE_NODE_TAP_RADIUS`、结点中心点击与地块寻路分流。
- `android/ui/world_map/relief_2d/map_exploration.gd`：高程地块拾取与名称提示的小范围命中。
- `android/ui/mobile/mobile_layout.gd`：不显示旧背包大底板，保留物品格、血条与头像。
- `systems/random/seed_registry.gd`、`ui/main_menu/menu_map_entry.gd`、`autoload/save_gateway.gd`：旧档构建渠道兼容和错误档退出保护；Android 对应文件同步。
