# 召唤怪物同屏与独立血条

本次整合保留 main 的 `EnemyRack` / `EnemySlot` 架构，并将 state 分支的实体快照、意图类型、阶段转换恢复和死亡退场接入同一显示单元。

## 显示与操作

- 所有敌人按数量在敌人区域横向分槽；槽位各自持有立绘、名称、血条、格挡、Buff 和行动意图，点击目标不会替换其他怪物身份。
- 数量变化时按已有 EnemyRack 规则重排全部槽位；点击区只覆盖立绘上部，为手牌与出牌区保留输入空间。
- 攻击意图显示伤害，防御意图显示格挡，其他行动显示特殊图标与“—”；显示只读取当前播放快照，不预演随机行动。
- 本体死亡后保留身份并降低立绘透明度；随从先完成血条归零，再淡出隐藏。阶段转换恢复时取消退场并恢复亮度。
- 目标箭头与悬停光晕沿用 main；嘲讽限制同时约束点击与规则目标。背包里的药水沿用 main 使用/丢弃菜单。

## 文件与边界

- `ui/battle/enemy_rack.gd` 负责槽位数量、区域与共享箭头。
- `ui/battle/enemy_slot.gd` 负责单槽布局、意图和快照状态；`show_snapshot_status()` 控制可点击性、死亡和恢复。
- `ui/battle/battle_test_scene.gd` 以 `_presented_enemies` 依次呈现完整敌方快照，统一调用生命与格挡绘制。
- `ui/battle/combat_feedback.gd` 按 enemy_id 查询目标；闪红结束读取当前 base_tint，避免覆盖死亡或恢复状态。
- 已删除无运行时引用的旧 `enemy_companion_view.gd`；正式战斗只使用 `EnemyRack/EnemySlot`，避免保留第二套失效的随从实现。

召唤、阶段转换、伤害、嘲讽继续走原事件队列；不改随机协议和存档格式。正式地图战斗继承同一 BattleTestScene。

## 验证范围

`tests/summoned_enemy_ui_selftest.tscn` 已改为检验真实 EnemyRack：真实后巷公爵阶段转换、逐个召唤快照、独立意图/伤害/治疗/格挡、真实鼠标选敌与出牌、多次同种召唤、嘲讽和死亡退场。`content_ui_selftest`、`battle_animation_selftest`、`battle_feel_selftest`、`world_encounters_selftest` 同步使用当前节点或单存档 API。

本次合并后的运行和截图验收以当前交付日志为准；源分支曾报告的 Windows/D3D12 结果不代表此合并树已经验证。所有存档测试使用隔离夹具。
