## 地图接口

`data/config/relief_2d/art_themes.json`：

- `floors`：楼层编号字符串 → 主题 ID。默认 `1:alchemy`、`2:slums`、`3:church_white`、`4:church_violet`。
- `themes`：主题 ID → `asset_id`、`atlas`、`manifest`。另有 `church_marble` 可手动配置；不把三套教堂配色随机混铺。
- 第四层只登记外观资源，现有三层玩法的进度上限不变。

新增素材目录位于 `assets/environment/env006`、`env007-white`、`env007-violet`、`env007-marble`，每套有 `atlas.png` 和 `manifest.json`。原画使用相同 4096×3686 配准、0.5 缩放和 0.6 墙面重复单位，沿用固定投影。每套顶面差分均放入 ground 池；三方向侧面共同构成一套 wall，不把方向当成随机差分。石堆和石子复用现有中性石材像素及轮廓；炼金工坊玻璃、纸张不会散布到其他主题。

CPU catalog 在石块及几何准备前确定，普通批次、异步揭雾批次、动态角色阴影各自绑定所属图集。材质与揭雾缓存包含主题身份，纹理按路径以弱引用共享，由活跃批次持有；不会在解析脚本时加载全部主题。配置或选中资源无效时回退炼金工坊外观。外观选取不消耗 SeedService 随机流，不改变地图分支、高度、墙体、通行、奖励或存档数据。

## 节点与界面接口

`systems/map/relief_2d/node_art.gd` 的 `EVENT_ART` 以稳定 `event_kind` 对应 PNG。图像裁除透明空白，最长边 512 像素，沿用现有底部锚点、透明分区、碰撞与已完成状态。原包来源、每张原图哈希和裁切边界记录在 `assets/map_nodes/alchemy/source.json`。未知事件展示问号，不提前透露事件类型；贴墙可见性仍使用既有迷雾和遮挡规则。精英素材接入不增加第一层精英数量。

商店仅在 ShopPopup 中增加 EVBG-013 层，原奖励弹窗 LootPopup 不受影响。场景预热器将商店背景加入节点预热，购买、选牌附魔、取消及存档走既有事务。事件背景来源见 `assets/events/source.json`；战场差分调用见文档 21。
