# 移除成就和局外解锁

本次变更取代旧文档中的成就、卡牌/残片/怪物解锁要求。地图关口与典籍格子开放属于局内规则，本次保留。

## 已移除

- 主菜单“成就”按钮、页面场景、脚本、UID 和 `data/text/achievements.csv`（含导入配置）。
- 全局成就判定请求、完成接口、完成信号，以及卡牌/残片/怪物的解锁变量、接口与信号。
- 文本目录的成就类别、成就 CSV 导入、解锁状态查询与进度监听。
- 图鉴“显示所有/已解锁/未解锁”模式及筛选按钮。卡牌、残片和怪物列表及详情均没有解锁状态。
- 新局按局外解锁过滤卡池的逻辑，以及 `starter_cards` 配置。配置目录内的卡牌直接可用；初始牌组仍为原来的八张牌，不会自动获得全卡组。

负面典籍残片继续不进入图鉴，但仍保留规则数据与战斗效果；商店、奖励包的稀有度和类型筛选不变。

## 存档兼容

继续使用单存档及现有版本号。旧文件的 `achievements`、`unlocked_cards`、`unlocked_fragments`、`unlocked_monsters` 读取时忽略，后续正常保存时不再写入，不要求玩家重开游戏。

局内牌组/副本附魔、物品、典籍布局、地图与随机种子、战斗状态、累计银币、设置和历史记录均保留。没有主动改写玩家真实存档；迁移回归只在隔离副本执行。

## 主要文件

- `state_machines/global/global_state_machine.gd`：删除局外进度和判定，兼容旧存档。
- `state_machines/run/run_state_machine.gd`：新局不再接收解锁卡列表，配置目录直接形成卡池。
- `autoload/save_gateway.gd`：更新新局预备流程。
- `systems/text/text_catalog.gd`：仅导入卡牌、残片、怪物及物品，直接返回全部条目。
- `ui/catalog/encyclopedia.gd`：去掉筛选模式，保留分类、详情、负面残片隐藏。
- `ui/main_menu/main_menu.gd/.tscn`：删除成就入口并收紧按钮底板；覆盖提示改为保留设置和历史记录。

## 验证

文本与图鉴（含实际鼠标与图形模式）、怪物图鉴、状态机、卡牌战斗、主菜单新建/覆盖、结算记录及玩家旧存档副本继续/保存回归均已通过。已删除的成就页面及数据可从 Git 历史恢复，不删除策划案和表格中的历史设计内容。
