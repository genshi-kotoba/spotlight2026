# 正式卡图按名称接入

本次按根目录 `卡牌表.xlsx` 的编号、卡名，将资产附件中的 70 张卡图接入桌面和 Android 工程。优先按完整卡名匹配；带括号说明的文件按卡名主体匹配，全部唯一匹配，无缺失。

- 资源位置：`res://assets/card/Card-001` 至 `Card-070`，后缀按文件真实编码采用 `.png` 或 `.jpeg`。
- 共 32 张 PNG、38 张 JPEG，首次导入时保留原始 1080 × 1840 尺寸；后续按用户要求裁掉外部白边，文件名与格式保持不变。
- 根工作簿只更新“卡牌”工作表的 70 个卡图路径单元格，保留其他内容与格式。
- 两端 `data/text/cards.csv` 只更新卡图路径，其余字段（包括现有效果文本）不变。
- 两端共用的手牌组件和图鉴预览均通过现有数据入口加载，无需修改卡牌效果或界面布局。

附件原件保留。原工作簿和两端旧占位图、CSV 备份保存在桌面工程的 `_local/card-art-sync/` 下，其中旧资源在 `backup/desktop/`、`backup/android/`，可恢复。该工作目录以 `.gdignore` 排除，避免备份资源和工具依赖被 Godot 导入。

## 卡图去白边

70 张卡图均按主体彩色矩形区域裁切，排除白页上的零散笔点与 JPEG 边缘压缩噪声；不抠除画面内部的白色图案，也不缩放或拉伸画面。裁切后 PNG 为 907 × 797，JPEG 宽 908–910、高 798–799。PNG 无损保存，JPEG 以最高质量重新编码，仍保留原 `.jpeg` 后缀。资源路径与表格不需要改动。

两端裁切前的完整原图备份在桌面工程 `_local/card-art-crop/backup/desktop/` 和 `backup/android/`。原附件仍未改动。该工作目录也通过 `.gdignore` 排除，不会被当作游戏资源导入。

## 插画框铺满

共用卡面 `ui/components/card/card_view.tscn` 的“插画位”使用 `STRETCH_KEEP_ASPECT_COVERED`：等比例放大并居中覆盖整个插画框，超出的边缘由 TextureRect 裁切，不再因图片与框比例不同而露出底色。保留原有插画锚点、卡框、文字、稀有度和类型配色，手牌、出牌区、背包、奖励选牌和图鉴共用此设置；Android 同步。此修改不再裁切或改写图片文件。

验证入口：`res://tests/card_art_assets_selftest.tscn`。分别使用桌面与 Android 工程运行，验证 70 条数据、精确文件名、PNG/JPEG 导入、裁切尺寸、四边没有整条白边、正式卡牌数据、手牌卡面及图鉴预览绑定。测试存档隔离在各工程 `.godot/`，不覆盖玩家存档。此验证在 Windows 上运行两套工程，不等同于 Android 真机测试。
