# 素材合成全牌组选牌

素材合成进入选取两张素材的阶段后，自动弹出完整牌组页面，不再在事件右侧使用纯文字选项列表选择素材。

- 完整牌组按永久副本逐张展示，包含同名牌、正式类型底图、卡名、效果与附魔符号。
- 卡面可直接点击选择／取消，金色边框与勾选标记表示已选；最多选择两张，选满后才能确认。
- 大牌组可滚动，列数按可用宽度调整。弹窗遮挡并禁用底层事件选项。
- 关闭按钮或 Esc 只收起弹窗，不消费素材；原事件页可重新打开，保留当前未提交勾选，也可取消并离开。
- 确认后沿用原有合成奖励三选一规则，完成奖励选择时才消耗指定两张副本并加入一张新牌。未修改事件规则或随机机制。
- 保存失败保留弹窗、勾选和原牌组，可重试。已提交的素材与奖励候选由原事件事务保存，重新载入不会重抽。

## 文件位置

- `ui/events/event_deck_picker.gd`：全牌组弹窗；`CARD_SCALE` 调整卡面尺寸，`GRID_GAP` 调整卡间距，`_ready()` 中的 panel 锚点调整弹窗范围。
- `ui/events/random_event_scene.gd`：素材合成阶段的弹窗入口和确认回调；其他事件仍使用原有界面。
- `tests/event_synthesis_picker_selftest.tscn`：专项测试场景。
