# main(new) 补充版本整合

目标：`spotlight2026-main`。来源：同级 `spotlight2026-main(new)`。
以现有 main 为主线，逐文件合入补充，不覆盖主线存档、卡牌和玩法规则。

## 合入内容

- Wwise 原生插件、平台配置、Windows/Android SoundBank、AudioService、事件 ID 及音频源工程。
- 开始菜单设置页；菜单和局内背包共用音乐/音效滑块组件。
- 地图角色两方向行走与待机动画、轮廓阴影、雾效、交互提示、脚步扬尘及换层淡入淡出节拍。
- 战斗目标箭头、敌人独立显示槽、伤害分档飘字、顿帧、血条残影、典籍连锁提示栈和结算配速。
- 背包悬停反馈、使用/丢弃菜单、数据变更即时刷新，以及开包放弃按钮和原子回滚事务。
- 新的发牌动画组件及补充版相关测试。

## 主线保留和冲突处理

- 成就页面与局外图鉴解锁机制不恢复，图鉴仍无解锁状态或筛选。
- 初始牌组仍是 3 张狮子之血、3 张灰吹银、2 张盾与矛；新局空背包、无残片。
- 典籍保持 main 的 4×5 格与局内格子开放规则；没有按过时说明回退至 12 格。
- 保留事件队列、规则引擎、奖励、附魔、随机事件、三层测试通关和结算历史。
- 保留历史详情确认按钮的真实鼠标点击修复。
- 补充版的等分敌人布局会缩小本体，已整合为本体固定原尺寸、召唤物分列两翼；随从带独立短血条、缩小意图和独立目标选择。
- 敌人槽按实体 ID 复用，召唤时不会销毁重建本体血条；点击有效区域不拦截手牌，漂浮文本避让敌方 HUD。
- 点击手牌沿用本次 UI 更新的即时编排，不再播放手牌飞入出牌区动画；拖拽、抽牌、弃牌、结算入弃及悬停让位动画继续保留。
- 战斗测试的残片编辑权限改为每个沙盒独立标记，测试操作不保存或覆盖当前正式对局。
- 使用/丢弃菜单点击外部即关闭，不吞掉原有“选残片再点典籍格”装配操作。

## 主要位置

- 音频入口：`autoload/audio_service.gd`；音量桥接：`systems/audio/audio_settings.gd`。
- 音量设置块：`ui/components/volume_settings.gd`；开始设置页：`ui/main_menu/main_menu_settings.tscn`。
- 地图角色配置：`data/config/relief_2d/actor.json`。
- 战斗宿主：`ui/battle/battle_test_scene.gd`；生产入口：`ui/battle/map_battle_scene.gd`。
- 敌人布局：`ui/battle/enemy_rack.gd`；单个单位：`ui/battle/enemy_slot.gd`。
- 补充合并回归：`tests/main_new_merge_selftest.tscn`。

## 验证与限制

29 组回归通过，覆盖主菜单/继续游戏、地图进入战斗、战斗输入与动画、召唤、奖励、附魔、典籍、随机事件、图鉴、终局记录等；资源导入通过，设置页与召唤战斗额外做图形模式检查。
真实存档只读复制后执行恢复/保存测试，源文件保持不变。无提交或推送操作。

音频插件可成功初始化并加载 SFX/Music Bank，设置滑块能更新同一配置对象，原生 RTPC 写入接口返回成功。
但本机测试中原生 RTPC 查询仍返回 100，未证明真实混音音量随滑块变化；需要音频侧联调当前 Bank/插件读回与混音曲线。
补充版只提供音频服务和独立 `tests/audio_test/audio_test.tscn`，未将所有游戏交互逐项绑定播放事件；本次未擅自增加事件映射，也未重制 SoundBank。
仅验证当前 Windows 环境；其他平台未做实际导出验证。

原补充版本、现有未提交改动、真实存档及工作区其他工程均保留。未复制原生库的 `~` 热重载临时副本；忽略该类副本。
