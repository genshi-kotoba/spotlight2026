# main（newest）优化版本整合

日期：2026-10-22。目标为当前桌面工程与独立 android 工程；不覆盖用户存档，不替换已有交付包。

## 已整合

- 音乐：主菜单音乐、炼金工坊/贫民窟与修道院/教堂顶的音乐分组；探索与战斗通过 Music_Combat 平滑交叉淡化，换区域淡出旧曲，冷恢复战斗时补齐音乐状态。Windows 与 Android 的新版 Init、Music、SFX 音频库、媒体元数据和 Wwise 工程资产均已同步。
- 地图：角色阴影按位移及时间限频，昂贵墙面阴影重建拆帧、限制碎片数量、动态退让；精英结点添加仅在可见时运行的蒸汽。第一层精英数改为 1，第三层改为 2；保留旧第一层零精英快照兼容。
- 战斗：原始 BOSS 本体全部死亡即胜利，召唤物不再拖住 BOSS 战斗；普通/精英仍需清除存活敌人。贤者之石调整为 96 生命、基础单次伤害 4，保留多次行动与召唤。
- 奖励：普通/稀有卡包排除负面牌 68/69/70；旧已打开卡包只替换不合法候选，保留有效候选和刷新状态，保存失败回滚。事件/怪物仍可正常给予负面牌。
- 随机事件：统一“暂时返回地图（保留事件）”入口，保留阶段、已支付代价、候选与选择草稿；悬置后素材失效可重新选择，不能免费刷新仍有效的候选。宝箱首次交互自动领取，保存失败保留重试；残堆保留手动领取。
- 诊断：运行 JSONL、存档校验原因、战斗队列、残片触发、奖励候选等日志；主菜单设置及局内设置增加导出按钮。日志写入各端自己的 user://logs，手机优先尝试下载目录，权限不允许时复制最近事件到剪贴板。

## 保留当前 main 的修复

新版中有部分旧实现，未直接覆盖：

- 游戏名“炼金术士的十日谈”、icon.png、导出图标及各端平台配置。
- 发行版 user://player/save/game.json 与编辑器 user://save/game.json 隔离；发行版不自动迁移编辑器测试档。
- 新游戏覆盖确认弹窗居中；读档失败仍能退出且不覆盖坏档。
- Steam/official 同源码构建的随机快照兼容与入口规范化，不重置共享随机流。
- 发行资源经 ResourceLoader 枚举、导出脚本中的 BOM 安全处理，避免重新引入包体缺少规则/文本的故障。
- 只有战斗胜利奖励含 2 个万灵药；事件、宝箱、残堆、离店不额外赠药，旧未领奖励仍过滤额外万灵药。
- 初始抽牌 6、每回合抽牌 3、基础牌位 3；解剖者伤害 2；既有升级与商店服务。
- Android 点击寻路、二次点击结点交互、缩小的结点点击范围、长按与拖动、放大 UI、安全区域及战斗左上空框修复。
