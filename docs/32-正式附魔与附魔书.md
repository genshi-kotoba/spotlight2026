# 正式附魔与附魔书

## 数据与入口

源表为项目外层 `卡牌表.xlsx` 的“附魔”页 A1:D23（编号、效果、类别、符号）。使用 `tools/import_enchantments.py` 只读导入到 `data/cards/enchantments.json`，不改写工作簿，也不重新导入卡牌或残片页。该工作簿的工作表维度声明错误，导入器显式 `reset_dimensions()` 后读取全部 22 条并验证编号和字段。

运行时不依赖 Excel/Python。`CardEnchantments` 统一管理资格、ID、两槽限制、符号与悬停文案，附魔保存于 `RunStateMachine.deck_cards` 中的具体 `copy_id`。同名卡不会共享附魔。

精英/BOSS胜利奖励新增一本附魔书，普通战斗不变。领取仍须点击奖励，书进入背包，不自动附魔。旧版尚未领取的五项精英/BOSS奖励继续可读，新版为六项；不补发历史战斗、不重置领奖标记。

## 使用流程

1. 背包点击附魔书，从正式 22 种中按种子生成三个不同附魔。
2. 点击附魔，二级页面只展示当前牌组的合格具体副本。
3. 点击其中一张卡或其附魔按钮，原子保存附魔并消耗一本书。

未完成选牌时不消耗；返回、关闭、无符合卡牌及保存失败都保留书。选项持久化，重开/读档不刷随机。书固定三选一、不受残片增选项影响，当前没有刷新功能。没有符合条件的牌时显示“没有符合附魔条件的卡牌”，可以返回改选或关闭保留。

“全部”适用所有牌；“攻击”对应现有 CSV 的“伤害”类；“格挡，和存在格挡的攻击”按显式指令识别格挡、嵌套重复格挡和伤害转格挡（例如 52 号）。不通过效果文案猜测资格。每张牌最多两个不同附魔。商店、许愿池和残片随机附魔复用同一资格检查与正式池；旧存档的 `damage_50` 仍生效，但不再进入新随机池。

## 战斗规则

`BattleEnchantmentRules` 是现有 `BattleRuleEngine` 的规则提供者，不另建效果队列。卡牌请求先进行附魔交互准备，再回到原卡牌编译器；伤害包装事件先提交前置效果，然后生成带独立 `damage_program_id` 的实际伤害指令。反应链继承来源时不会误放大残片、中毒或其他牌的效果。

| 编号 | 实现 |
| --- | --- |
| 1 | 从手牌弃置后改入出牌队列尾部 |
| 2 | 整张牌总共触发两次，沿用原重复计数和暂停机制 |
| 3 | 直接伤害 +30% |
| 4 | 不占出牌数量，战斗中获得此附魔也即时更新 |
| 5 | 触发后生成半效一次性副本到手牌，不继承附魔、不加入永久牌组 |
| 6 | 按用户勘误：先对自己造成原额伤害，再对敌人造成双倍伤害；自伤致死时终止后续行动 |
| 7–9 | 弃置手牌时：敌全体 5 伤／抽 3 张／获得 5 格挡 |
| 10 | 下一次指针移动到的牌额外触发一次 |
| 11 | 下一次指针移动前移一位；弃置时指针已在首格则抽一张 |
| 12 | 弃置手牌时获得 1 力量、敌全体获得 1 易伤 |
| 13 | 对敌方格挡的消耗翻倍，不把生命伤害也翻倍 |
| 14–15 | 按实际造成的生命损失获得 50% 格挡／恢复 25% 生命 |
| 16 | 每次触发抽一张牌 |
| 17–18 | 每次直接伤害之前先给目标 1 易伤／1 中毒 |
| 19 | 每次直接伤害之后给目标 1 虚弱 |
| 20–21 | 每次整牌结算前可弃 1 张手牌或跳过，本次伤害／格挡 +50%；重复触发时分别选择 |
| 22 | 本牌直接伤害击杀时恢复 2 生命，最后一个敌人也能结算回复 |

百分比逐步向下取整；力量/虚弱先计算，附魔倍率在易伤之前。5 号半效副本的伤害、格挡、回复、Buff 层数及抽/弃数量减半向下取整，保留指针、换位和重复等结构效果；手牌满时按现有溢出规则进入弃牌堆。用后移除发生在计算下一牌索引之前，避免跳过后牌。

“弃置”指手牌主动/效果/随机弃置，结算完出牌区统一进入弃牌堆不再次触发。沿用原事件队列和指针循环上限，并增加同链弃牌来源去重与每回合 64 次弃牌反应上限。

6 号表格仍保留原始错误文案，导入脚本按本次确认进行运行时勘误。此前明确暂缓的 61 号牌附魔继承仍保持待接入，不在这次改写其卡牌规则。

## 表现和验证

统一 `CardView` 模板新增左上角金色符号层，不拦截鼠标。手牌、出牌区、抽/弃牌堆、飞牌、拖拽、大图、结算预览、牌组和附魔目标页都按具体副本显示；图鉴模板不显示实例附魔。两个符号随卡面一起缩放，悬停仍显示完整附魔效果。背包书使用独立 SVG 占位图标。

`tests/enchantment_book_selftest.tscn` 使用 `.godot/` 独立存档，覆盖正式表 22 条、精英/BOSS发书、普通不发、两级选择、空态、取消、原子回滚、同名副本、双槽、不重复、冷恢复、字符覆盖、各附魔规则、重复时分别付费、指针实际回跳、一次性牌移除及实际战斗点击。截图与日志保存在忽略目录，不改动玩家存档。
