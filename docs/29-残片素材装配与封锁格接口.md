# 残片素材、封锁格与说明接口

2026-10-19 用户确认：实际典籍为 **4列×5行、20格**，正式初始开放9格；本轮隔离验收先开放12格，剩余格子灰显。本说明取代旧文档中关于4×3容量、额外两行为装饰的约定，不更改残片随机属性或连锁次数规则。

## 棋盘与兼容

- `RelicBoard.COLUMNS / ROWS / CELL_COUNT` 为4/5/20。槽位索引为零起始、按行排列，`index = row * 4 + column`。界面和调用方从常量取尺寸。
- `DEFAULT_UNLOCKED = [0,1,2,4,5,6,8,9,10]`，即左上3×3。新局配置可传 `relic_unlocked_cells: Array`；测试使用 `range(12)`，不是开放全部20格。
- `is_unlocked(index)` 查询封锁状态；`set_unlocked_cells(indices)` 设置可用格，`unlock_cell(index)` 开放单格。索引须为0–19且不重复的整数；JSON整数值允许恢复为float，布尔值、小数、重复、越界均拒绝。已装配的格子不能直接封锁。
- 棋盘存档为version2，含 `columns/rows/cells[20]/unlocked_cells`。version1的4×3存档保留原12格、原残片ID和颜色，补8个空格，并保持原12格开放。迁移不重抽残片。
- 跑图库存与战斗的 `player.encounter_relic_board` 各自迁移自身快照，不拿当前背包覆盖战斗构筑；已消耗的 `relic_runtime.chain_charges` 保留。
- 运行中编辑仍只调用 `RunRewards.equip_fragment / move_fragment / unequip_fragment`，走原存盘事务；锁格拒绝、保存失败回滚、战斗只读。不要只修改UI来绕过锁定。解锁费用与进度规则尚未新增，本轮仅提供状态与接口。

## 素材与显示

- UI-020：`assets/ui/UI-020/1.png`至`20.png`，对应槽位0–19；这些素材共用大画布，由 `RelicPieceArt.slot_texture(index)` 缓存裁切有效区域。
- UI-021：`assets/ui/UI-021/UI-21.png`，单片模板；`RelicPieceArt.template_texture()` 返回裁切后的模板。
- 物品图标调用 `ItemIcon.make_item(item, side, path="")`，传入物品记录以区分类型。`fragment`、`fragment_pack`统一显示单片模板，不因物品表缺行而回退到药瓶；普通物品仍支持原 `make(path, side)`，药剂图标不变。
- 背包始终用单片模板。装配与HUD使用目标槽位的拼图片；挪到新槽时只改变外形，名称、颜色、主能力、附属词条和物品副本身份不变。
- 装配拼片的颜色直接调制纹理，不叠加常驻矩形底框；封锁格沿拼片透明轮廓灰显，保留锁字和输入守卫。普通背包格框与临时范围提示保留。
- 拖拽到已开放槽位时，直接在该槽位预览目标拼片、颜色与名称，暂藏原内容，不使用方块底框或跟手方块；移出或进入封锁格时恢复跟手模板，不能投放到封锁格。
- 20格均展示；未开放格灰显并标注“未解锁”。本轮测试前3行开放、后2行封锁。

## 描述与动效

统一调用 `RelicFragmentData.rich_text(title_size=30)`，紧凑悬停使用20号标题、15号正文。名称加粗、放大并保留残片颜色。`rich_description()` 只产生说明正文，顺序固定为：

1. 蓝色装载词条：`当装载该残片时，……。`（存在时置顶）。
2. 绿色触发：`当……时，触发……范围。`，或白色效果：`被触发时，……。`。
3. 红色负面：`负面：……。`（存在时置底）。

“整个典籍”表示棋盘中除自身外的其他格子，避免扩容后继续写死12格。没有残片或仍封锁的格子不会产生实际效果。

富文本标签先调用 `CommonUiSkin.setup_relic_text(label, body_size)`，再开启BBCode。该入口配置中文常规/粗体字形并只安装一次 `RelicTextMotion`。只有红色负面词条使用 `[relic_motion]` 标签；标题、蓝色装载与绿色／白色主能力保持静止。负面词条的逐字偏移/转动与怪物文字共用 `TextGlyphMotion` 采样器；动效不推进玩法PRNG、不改文字颜色或可见性。普通物品说明继续使用纯文本。

## 范围与入口

装配拖拽及已装触发残片悬停，按 `RelicBoard.neighbors(index, reach)` 预览一跳范围，包含开放的空格，排除封锁格；不预测多跳连锁。效果型不显示触发范围。换片成功且鼠标不动时也保持悬停；离开、取消拖拽、关闭或换页清理高亮。

`RelicBookView.open_requested` 为左上微缩典籍点击信号：地图经 `RunStatusPanel.menu_requested` 打开Tab背包；战斗打开同页但只读。点击由UI消费，不透传为地图移动或战斗操作。

## 验证与交付边界

测试地图、自动化脚本、隔离存档及原生验收应用留在仓库外。正式新局不赠送测试残片，不提供重复战斗或测试传送。测试构建开放12格；正式新局仍按上述配置默认开放9格。
