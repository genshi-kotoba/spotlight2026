# 卡牌预制件与编辑器预览

本次从 `spotlight2026-prg-007-008-cards` 合入卡牌表现组件，但继续使用 main 已有的卡牌、Buff 与战斗适配接口。没有加入完整战斗界面。

## 组成

| 内容 | 路径 |
| --- | --- |
| 通用卡面场景 | `ui/components/card/card_view.tscn` |
| 卡面脚本 | `ui/components/card/card_view.gd` |
| 八张卡框配置 | `data/config/card_face_set.tres` |
| 编辑器预览插件 | `addons/card_preview/` |
| 卡面自测 | `tests/card_view_selftest.gd` |

插件已在 `project.godot` 启用。重新打开 Godot 后，选择一份 `CardData` 资源即可在检查器和右侧“卡牌”面板看到实时预览；“项目 → 工具 → 卡牌大图”可打开独立预览窗口。

## CardData 字段

main 保留策划案定义和既有程序接口：

- `card_id`：稳定标识。
- `card_name`：卡名。
- `description`：效果描述。
- `rarity`：`COMMON` / `RARE`，分别使用“日”/“月”卡头。
- `kind`：`DAMAGE` / `BUFF` / `SHIFT` / `SPECIAL`。
- `face_tint`：`GRAY` / `RED` / `BLUE` / `YELLOW`，只控制卡框颜色，不替代卡牌类型。
- `effects`：按顺序执行的效果资源。

## 使用

```gdscript
var card: CardView = preload("res://ui/components/card/card_view.tscn").instantiate()
add_child(card)
card.set_card(load("res://data/cards/bonk_1.tres"))
card.set_texts("卡名", "效果文本", "介绍文本")
card.set_face(CardData.Rarity.COMMON, CardData.FaceTint.GRAY)
card.set_art_texture(texture)
```

卡面内部不处理点击、拖拽或悬停，交互由外层容器负责。卡面几何保存在 `.tscn` 中，脚本只更新文本和贴图。
