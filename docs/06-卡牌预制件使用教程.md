# 卡牌预制件使用教程

这份文档讲 PRG-007 / PRG-008 的卡牌数据与效果，以及 PRG-013 的卡面模板，面向策划、美术与要接入卡面的程序。内容覆盖四件事：不运行游戏查看一张卡的卡面、新建与修改卡牌、在编辑器里调卡面排版、把卡面用到别的界面。

涉及的东西：

| 是什么 | 在哪 |
| --- | --- |
| 卡牌数据（一张卡一个文件） | `data/cards/*.tres` |
| 卡面模板（一个卡面一份） | `ui/components/card/card_view.tscn` |
| 8 张底图的成套数据 | `data/config/card_face_set.tres` |
| 检查器预览、右侧「卡牌」面板、卡牌大图窗口 | `addons/card_preview/` |

## 0. 先决条件

1. Godot 4.7.2，打开本工程
2. 插件在编辑器启动时装载，已经打开着的编辑器要重启一次才会加载它。重启后不需要额外设置，`project.godot` 里已登记
3. 确认插件是否已加载：菜单「项目 → 项目设置 → 插件」，列表里应有一项「卡牌预览」，状态为启用

中文字体走系统字体（微软雅黑）。Windows 上开箱可用，换平台要另配字体。

## 1. 看一眼一张卡（不用运行）

双击 `data/cards/bonk_1.tres`，检查器最上面是这张卡的卡面，下面是 `卡牌标识`、`卡牌名`、`描述`、`稀有度`、`颜色`、`效果` 这些字段。

改 `卡牌名`、`描述`，或换 `稀有度` / `颜色` 两栏，卡面在 0.15 秒内跟着变，不需要保存、切换或按 F6。

## 2. 要看大图：三个地方

| 想要多大 | 在哪 | 说明 |
| --- | --- | --- |
| 小图 | 检查器最上面 | 跟着正在改的那张卡，宽 144 px |
| 中大 | 编辑器右侧「卡牌」面板 | 里面只有一张卡面，没有别的卡、标签或按钮。宽度可以拖，卡面自动缩放居中，最大 1.2 倍 |
| 大图 | 菜单「项目 → 工具 → 卡牌大图」 | 660 × 1020 的独立窗口，里面同样只有一张卡面，倍率接近 1.2（约 576 × 982）。窗口可以拉大，也可以挪到第二个显示器 |

三处显示的都是同一张卡，即当前正在看的那张。判定顺序：

| 顺序 | 操作 | 显示 |
| --- | --- | --- |
| 1 | 在检查器里编辑某张卡（在 FileSystem 里点 `.tres` 也会让检查器切过去） | 那张卡 |
| 2 | FileSystem 里选中卡牌文件（检查器没在编辑卡时） | 那张卡 |
| 3 | 在界面场景里选中一个卡面节点 | 那个节点身上挂的卡 |

三处都没有时显示为空。改字段三处同时跟着变，因为它们走的是同一份展示逻辑。

## 3. 新建一张卡

1. 在 FileSystem 面板里选中 `data/cards/`，右键 → 新建 → 资源
2. 搜索框输 `CardData`，选中，创建
3. 存成 `data/cards/<card_id>_1.tres`。同一个 `card_id` 可以有 `_1` `_2` 两份，用来区分同名不同实例
4. 填字段：

| 字段 | 填什么 |
| --- | --- |
| `卡牌标识` | 稳定标识，小写英文，例如 `bonk`。卡与卡之间互相引用、存档里记的都是它，定了不要改 |
| `卡牌名` | 卡面上显示的名字 |
| `描述` | 卡面上的效果文本。动态数值（例如「造成 X 点伤害」）的拼装属 PRG-014，尚未实现 |
| `稀有度` | 卡面第一栏：`日` / `月`，默认 `日`（源码里是 `稀有度档.日` 等）。决定卡头形状 |
| `颜色` | 卡面第二栏：`灰` / `红` / `蓝` / `黄`，默认 `灰`（源码里是 `颜色档.灰` 等）。决定卡框色调 |
| `效果` | 这张卡打出时执行的效果，见下 |

两栏一选，卡面立刻换成对应的底图，不需要另外指定。稀有度这一栏对应策划案 2.4 的稀有度，但两档在玩法上叫什么还没定，选项名暂用底图的名字（日 / 月）；颜色同理。改枚举名时，底图的对应关系在 `CardFaceSet`，两处一起改。

5. 加效果：`效果` 一栏点「添加元素」，下拉里是全部继承 `GameEffect` 的效果类，卡牌效果与 buff 效果都在里面。选中后只显示那个效果自己的字段（例如攻击的 `数值`、抽牌的 `张数`），填完即可
6. 想要新效果：照着 `systems/cards/effects/` 下已有的文件新加一个 `.gd`，不需要改任何已有文件。格式见 `docs/01-项目结构与目录约定.md` 的「卡牌与 buff 的目录与格式」一节
7. 自检：在 FileSystem 里右键 `systems/cards/card_catalog.gd` → 运行（快捷键 Ctrl+Shift+X）。输出面板会列出全部卡牌（含每张的卡面两栏），并报出 `卡牌标识` 重复、`卡牌名` 为空、`效果` 为空这几类问题

## 4. 调卡面排版（策划与美术最常做的事）

打开 `ui/components/card/card_view.tscn`。根节点下面五个子节点，按从下往上的绘制顺序：

| 节点 | 是什么 |
| --- | --- |
| `插画位` | 插画位。位置正好是底图上那块透明洞，插画在卡框下层，从洞里露出来 |
| `卡框` | 卡框底图，铺满整张卡 |
| `卡名` | 卡名 |
| `效果文本` | 效果文本 |
| `介绍文本` | 介绍文本，默认隐藏，给了文本才出现 |

| 想做什么 | 怎么做 |
| --- | --- |
| 挪文字位置、改文字框大小 | 选中 `卡名` / `效果文本` / `介绍文本`（或 `插画位`），在场景视图里直接拖，或在检查器里改锚点与偏移 |
| 改字号 | 选中节点 → 检查器 Theme Overrides → Font Sizes → `font_size` |
| 改文字颜色 | 选中节点 → 检查器 Theme Overrides → Colors → `font_color` |
| 换底图 | 选中根节点 → 检查器里 `稀有度`（日 / 月）与 `颜色`（灰 / 红 / 蓝 / 黄）两个下拉 |
| 放插画 | 选中 `插画位` → 把图片拖到 `Texture` 上 |
| 改整张卡的设计尺寸 | 改根节点的 `offset_right` / `offset_bottom` 与 `custom_minimum_size`（现在是 480 × 818）。五个槽位用的是锚点百分比，会跟着等比走，字号要自己重调 |

两条前提：

- 脚本不会挪任何节点。卡面脚本只写文本、只换贴图，拖完就生效，运行起来也不会被挪回去
- 底图导入时缩到最大边 1024（600 × 1024），卡面按 480 × 818 显示，放大后偏糊是正常的。清晰版在 `_local/ui-001/extract/`（不入库）与飞书资产表 UI-001

## 5. 把这张卡用到自己的界面里（程序）

实例化 `ui/components/card/card_view.tscn`，然后按需调用：

```gdscript
# 塞数据。编辑器里也可以直接把 .tres 拖到节点的卡牌数据上
card.set_card(卡牌数据)                  # 传 null 即清空
card.set_texts("卡名", "效果", "介绍")      # 只想自己填文案时用；介绍为空则自动隐藏

# 换底图。挂了卡牌数据时底图由数据里的两栏决定，要单独指定用下面这个
card.set_face(CardData.稀有度档.日, CardData.颜色档.灰)
card.set_face_texture(texture)            # 单张覆盖，绕开两个栏位
card.set_art_texture(texture)             # 插画位

# 信号
card.card_data_applied.connect(_on_card_applied)   # 参数是卡牌标识
```

四条约定：

1. 卡面恒为 480 × 818。要显示多大改节点的 `scale`，不要改卡面自己的尺寸，手牌排布与缩放分离
2. 卡面不吃鼠标事件（内部节点 `mouse_filter` 全是 `IGNORE`）。点选、拖拽、悬停都由容器处理
3. 不要在别的脚本里改卡面内部节点的 `position` / `size` / `font_size`。排版归场景，改一次就在编辑器里看得见
4. 节点上那两个 `稀有度` / `颜色` 只在没挂 `卡牌数据` 时起作用。挂了数据时以数据为准，卡面脚本不会把数据写回这两个属性：它们要存进 `.tscn`，`@tool` 脚本一写就会把场景标脏，一保存就把某张卡的两栏写进预制件

实时预览的工作方式：插件在 `CardData` 的检查器顶部插一个预览控件，控件内是一份 `card_view.tscn`。它不靠信号刷新，`Resource.changed` 不会因为属性赋值而触发，所以只能按 0.15 秒轮询比对卡面显示的五个字段。移植参考的 Unity demo 里，`CardPreviewer` 同样按固定间隔轮询。

## 6. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 检查器里没有卡面预览 | 编辑器在插件加载之前就已经启动。重启编辑器；或在项目设置 → 插件里确认「卡牌预览」已启用 |
| 右侧没有「卡牌」面板 | 同上。面板被关掉的话，从编辑器右上角的布局菜单里重新打开 |
| 大图窗口不见了 | 菜单「项目 → 工具 → 卡牌大图」再开一次；关掉窗口不会卸载插件 |
| 面板里显示的卡不是当前在看的那张 | 面板先看检查器正在编辑什么，再看 FileSystem 选中什么。点一下要看的那张 `.tres`，让检查器切过去即可 |
| 卡面文字是方块 | 系统字体没取到。Windows 上应取微软雅黑，换平台要另配字体 |
| 文字溢出卡框 | 有意为之，不自动缩字号。缩小字号或把槽位拖大 |
| 打开 `.tres` 只有字段没有卡图 | 同第一条 |
| 底图有点糊 | 导入时缩到最大边 1024，正常 |
| 改了 `card_view.tscn` 但别处没变 | 别处引用的是同一个场景，会一起变；若没变，检查那个界面是不是自己另做了一套卡面 |
| 改完插件脚本没反应 | 插件脚本的改动要重启编辑器才生效 |

## 7. 边界

- 不要改 `CardData` 的字段集合。要加字段（例如费用）先提出来，动了要连带改 16 张原型卡与校验工具
- 不要把卡面接到战斗状态机上。卡面只认 `CardData`
- 不要在卡面脚本里设几何（`position` / `size` / `font_size`）。自测里有一条会拦这个
- 不要直接改 `addons/card_preview/` 里的插件文件，除非是改工具本身
