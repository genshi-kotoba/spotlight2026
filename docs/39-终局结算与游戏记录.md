# 终局结算与游戏记录

## 流程

- 死亡：等战斗表现队列收尾后冻结原场景，将旧画面淡出至本层战斗背景。中央依次淡入“你死了”、死因、累计获得银币、本局战斗数。
- “你死了”使用红色及与典籍负面效果相同的 `RelicTextMotion` 抖动。战斗死亡显示本体怪物名称，事件死亡显示实际事件名称。
- 全部文字显示后等待 1 秒，移到原背包人物栏的位置，展开最终背包。人物立绘不显示。
- 最终背包只读：可滚动、查看卡牌大图和物品/残片说明，不能用药、开包、附魔、装卸残片或进入设置。
- 确定按钮在详情展开完成后才出现；确认成功保存后返回开始界面。失败保留当前结算，可重试；连续点击不会重复跳转或新增记录。
- 通关显示金色“结束了”，没有死因，其余流程相同。
- **当前测试版以第三层 BOSS 为通关终点。** 必须完成最后一场奖励领取后才结束游戏，记录包含已领取但尚未打开的卡包、残片包和附魔书。
- 最后 BOSS 奖励尚未领完时可存档继续；不会提前生成通关记录。第四层仍未制作。

## 文件位置

| 文件 | 职责 |
| --- | --- |
| `ui/results/run_settlement_view.gd` | 结算背景、逐行动画、文字位置、只读背包及确定按钮；历史详情复用同一视图 |
| `ui/results/run_records.tscn`、`ui/results/run_records.gd` | 开始界面“记录”进入的历史列表，点击直接展示最终背包，不重播结算动画 |
| `autoload/run_results.gd` | 等待表现队列、冻结场景、截图淡出、三层通关和确认返回协调 |
| `systems/run/run_history.gd` | 历史排序、结算文案、以最终快照创建独立只读背包 |
| `state_machines/run/run_state_machine.gd` | 累计银币、战斗数、终局快照及名称/背景来源 |
| `state_machines/global/global_state_machine.gd` | 结束时追加记录并通过正式存档网关原子保存 |
| `ui/hud/run_menu_overlay.gd` | `settlement_mode`：去除人物立绘、禁用构筑/消耗操作，保留查看能力 |
| `ui/main_menu/main_menu.tscn`、`ui/main_menu/main_menu.gd` | 新增记录按钮和跳转入口 |

动画可在 `run_settlement_view.gd` 的导出变量调整：

| 参数 | 默认秒数 |
| --- | ---: |
| `fade_seconds`：原场景淡出 | 0.8 |
| `line_seconds`：每行淡入 | 0.55 |
| `line_gap`：行间停顿 | 0.35 |
| `hold_seconds`：最后一行后等待 | 1.0 |
| `move_seconds`：文字左移 | 0.65 |

视图以 1920×1080 为逻辑画布，随窗口等比缩放。中央文字起点为 `(700, 270)`，最终位于 `(124, 300)`、缩放 `0.6`；确定按钮位于 `(1580, 960)`。

## 数据与兼容

- 继续沿用单存档文件，记录存于 `run_history`，没有引入额外存档槽。
- 新记录保存 `total_silver_earned`、最终背包、卡牌副本及附魔、典籍棋盘、物品、背景、死因、战斗数与结束时间。
- 累计银币统计所有实际获得，不因消费/丢失减少；失败事务回滚会一并回滚累计值。
- 记录按结束时间从新到旧；同秒记录保留实际发生顺序。仅展示死亡/胜利，不把放弃或覆盖旧局当作死亡。
- 查看历史使用独立的非活动局快照，不替换当前游戏、不消耗种子随机流、不重新抽卡或发奖励。
- 老的活动存档缺少累计字段时，以已有银币余额作为迁移起点；过去已经花掉的银币无法追溯恢复。
- 老历史没有完整背包时仍能展示保存过的卡组；没有累计银币时明确显示“未记录”，不伪造统计，也不读取当前背包或测试典籍配置。

## 验证

- `tests/run_settlement_selftest.tscn`：累计/回滚、旧档迁移、终局落盘、真实战斗死亡动画、只读背包、确认重试、主菜单记录入口、历史详情和同秒排序。
- `tests/world_encounters_selftest.tscn`：真实地图战斗、前两层推进、第三层 BOSS 奖励与冷恢复、通关结算、败北结算。

- `tests/battle_rewards_selftest.tscn`：奖励和背包回归，失败先结算再确认返回。
- `tests/shop_enchantments_selftest.tscn`：商店和附魔回归。
- `tests/save_crash_recovery_selftest.tscn`：只在玩家存档隔离副本上验证读取、新建及再次保存，不覆盖真实玩家文件。

## 记录详情确定按钮修复

背包的 `open()` 会将背包节点移到父节点末尾。Godot 的鼠标命中顺序不由 `z_index` 决定，原先作为同级节点的“确定”按钮虽然显示在面板上方，实际点击却被背包拦截。

现在确定按钮放置在背包内部、卡牌大图遮罩之前：正常可点击返回记录列表；大图打开时先由遮罩接收点击关闭大图，不穿透退出详情。专项测试改用实际鼠标按下/松开验证死亡结算、不同记录详情的确认，以及大图遮罩，不再只直接调用关闭方法或发出按钮信号。
