## 行走调用规则

实现位置：`ui/world_map/flat_2d/map_demo.gd`，平面和 2.5D 入口共用。

- `speed_multiplier` 是基础倍率，默认 `2.0`；现有移速滑块调整它，冲刺不会覆盖它。
- `WALK_ACCELERATION_DELAY=2.0`：实际连续移动的等待时间。
- `WALK_ACCELERATION_DURATION=1.0`：从基础倍率过渡到最大倍率的时长。
- `WALK_ACCELERATION_MAX=1.5`：相对基础倍率的上限；默认 `2.0 × 1.5 = 3.0`。
- 键盘与按住鼠标移动共用逻辑。转向、沿墙滑动保持累计；无方向、完全堵住、暂停、失去窗口焦点、进入节点交互及重新载图会重置。
- 计时依据 `Session.move_actor()` 之后的真实位移；不会顶墙蓄速。计时不存档，恢复游戏从基础速度开始。
- 保留脚部碰撞半径与碰撞路径插值。HUD 同时显示当前倍率和基础倍率。

## 节点与事件接线

首层配置在 `data/config/relief_2d/exploration.json`，使用 `content_profile="alchemy_floor1"`。生成器配置中的 `events=4` 包含商店、宝箱和两个事件的位置额度，不表示四个随机事件；以最终节点配额为准。

事件稳定目录在 `systems/map/flat_2d/alchemy_event_catalog.gd`。`RandomEventCatalog.index_for_map_node(seed, map_id, node)` 优先读取新节点的 `content_id="alchemy/events/<id>"`，旧节点使用原有独立事件随机地址。已有事件事务恢复时继续使用保存的身份，不重新抽取。

`Session.request_node()` 记录事件 `opened`，仅揭示身份；奖励和完成由现有事件事务处理，地图不会自动发奖。美术新增地图图像时更新 `relief_2d/node_art.gd` 的映射；EVBG 场景背景不能直接当作节点图像使用。

节点几何由 `flat_2d/node_geometry.gd` 统一处理，渲染与碰撞共用：

- 战斗、商店、Boss、宝箱用 `body_radius` 声明逻辑平面圆形占地。
- 随机事件用 `body_capsule` 声明细薄占地，不用圆形碰撞或圆形影子；当前方向适配固定水平偏转角。
- 只对已知节点启用实体占地，不能借碰撞提前泄露未知节点。
- 关口是否通行以 Session 完成状态为准，不能只隐藏图像。完成通知及领奖回图仍经 EncounterFlow。
- 贴图 alpha 轮廓参与角色遮挡，透明留白不是实心矩形；角色脚部半径维持 `0.18`，不通过缩小角色碰撞掩盖对齐问题。

## 通用 UI 接口

新页面使用 `ui/components/common_ui_skin.gd` 的 `CommonUiSkin`，显式绑定到通用控件，不安装全局 Theme 或递归替换专用卡面。

```gdscript
panel.add_theme_stylebox_override("panel",
    CommonUiSkin.panel("panel", Vector4(24, 20, 24, 20)))
CommonUiSkin.style_button(button)
CommonUiSkin.style_dialog(confirm_dialog)
```

`Vector4` 边距顺序为左、上、右、下。`panel()` 支持常规面板、小面板、横条、提示与行项目等用途；`style_dialog()` 同时适配确认 / 取消按钮。

`CommonFrameStyle` 用底纹和九宫格边框绘制，源图裁角与显示裁角分别计算；`CommonButtonStyle` 用水平三段切片保持按钮端部比例。两者绘制时直接使用纹理区域，不逐帧生成或缩放 Image。矩形命中范围保留，避免透明装饰处把点击漏给地图。

素材位置为 `assets/ui/UI-002/`、`UI-003/`；卡牌、角色、遗物槽位等专用资产维持原引用。

## 调试开关与兼容

仅本地测试时在 ProjectSettings 显式设置：

```gdscript
ProjectSettings.set_setting("debug/map_battle/enable_instant_victory", true)
```

仓库 `project.godot` 默认关闭。`EncounterFlow.can_debug_finish_battle()` 和战斗状态机会再次校验开关、当前绑定、玩家行动阶段与事件队列空闲状态；动画、选择、开局和结算期间禁用，重复点击不会重复领奖。该入口跳过伤害、反伤、变身等战斗反应，不能替代正式出牌测试。

存档协议不升级：旧局沿用已保存节点、地图几何和配置；不声明节点实体的旧快照不强行补写碰撞字段或改变指纹。旧状态缺少 `opened` 时按已完成 / pending 事件补齐。新配额与新实体只应用于新生成地图，不重建已有局；种子系统与业务随机流继续沿原接口使用。

## 已验证范围及已知边界

本次代码与原生预览验证版本一致。三个真实种子的节点、贴墙、缩放、碰撞、关口领奖回图专项共 403 项检查无失败；最新 UI、行走与流程回归共 387 项检查无失败，另验证 30/60/120 Hz 行走计时和按钮渲染。原生流程覆盖正式出牌、商店、事件恢复、存读档和三层推进；使用调试胜利的部分不作为完整战斗验收。

以下为当前游戏既有边界，本次未补成正式玩法：

- 宝箱目前仅展示，尚未接入领取奖励与完成状态。
- “与兽共斗”“伤害石碑”“素材升级”仍有明确模拟环节。
- 当前实现前三层，第三层 Boss 奖励结束后等待第四层；没有最终通关结算，也不能返回已离开的楼层。
- 长回归退出时有 ObjectDB 实例残留警告，原因待定位；其他平台和长期内存稳定性尚未完整验证。
