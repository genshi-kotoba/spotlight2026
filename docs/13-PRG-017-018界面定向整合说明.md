# PRG-017 / PRG-018 界面定向整合

本次从 `spotlight2026-prg-017-018-ui` 接入战斗、探索与冒险菜单界面。目标工程为 `spotlight2026-main`，不切换 Git 分支，不替换 main 的牌组、卡牌表、正式效果、buff、状态机、规则引擎或存档格式。

## 已接入界面

- 战斗：新版血条、buff 行、头像与立绘占位、背包占位、典籍面板、右侧半叠出牌列、底部手牌、悬停放大和让位动画。
- 探索：左上状态面板、右上小地图、底部操作与楼层信息栏。
- 冒险菜单：地图、背包、设置三页；点击头像打开，点击小地图进入地图页；Tab 背包、M 地图、Esc 设置/关闭，Q 切换地图交互目标。
- 地图查看器：独立 2D 世界，可缩放、拖动，仅查看，不改变角色位置或探索状态。

## main 优先的冲突处理

- 战斗测试场景仍使用 main 配置的牌组；正式卡测试入口仍提供 1–70 号及分组测试，不改成 UI 分支的旧固定测试牌组。
- 正式卡牌仍由 CSV 与 `FormalCardCatalog` 创建，效果继续走 main 的事件队列与规则引擎。保留分类底图：伤害红、buff 蓝、移位黄、特殊灰，以及普通/稀有两套形状。
- 冒险菜单读取当前战斗四个牌区的真实实例；跑图时读取 `RunStateMachine.deck`，支持重复卡和旧原型标识，不构造新初始牌组，也不修改牌组。
- 保留 main 的动态出牌上限、不占牌位卡、锁牌、空牌位、弃牌堆选择插入、手牌弃置与结算快照；出牌区卡面继续为手牌的二分之一。
- 保留 UI-017 结算指针，同时接入新版金色高亮框。
- 典籍格数沿用 main 的 4×3，而非导入交付说明中提及的尚未合入 4×5；菜单和战斗面板均从 `RelicBoard` 获取尺寸。
- 主菜单开局、解锁与存档仍由 main 管理。没有为跑图默认添加正式测试牌组；默认空牌组仍是现有配置的结果。

## 整合修正

- 菜单和牌堆弹窗层级高于悬停手牌，避免卡片浮到弹窗上方。
- 切换菜单页不会覆盖打开前的暂停状态；关闭后恢复原状态。窗口失焦造成的临时暂停会在重新聚焦后解除。
- 地图查看器首次打开即适配范围，且与外层地图隔离，避免重复渲染或滚轮串操作。
- 结算/交互选牌期间暂不打开战斗冒险菜单；保存失败时留在当前场景。
- 伤害预测未实现，显示“—”，不使用 UI 分支写死的示例数值。头像、背包槽及意图仍沿用 UI 分支的占位表现，不代表新增对应玩法。
