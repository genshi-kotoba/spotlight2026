# 开始界面定向整合说明

来源：工作区 `spotlight2026-prg-016-021-main-menu/ui/main_menu/`。只引入 PRG-016 的开始界面、三档选择、档案卡、提示条和确认弹窗；其余实现以当前 `spotlight2026-main` 为准。

## 范围

- 原始定向整合保留来源的六个按钮、标题占位、背景贴图位、当前档案与版本号布局；后续文本系统任务新增第七个“图鉴”按钮，详见 `11-文本系统与图鉴成就界面.md`。
- 不引入来源的 `ui/settings/`、`ui/placeholder_run/`，不覆盖其卡牌、地图、状态机、种子、战斗或典籍代码。
- 来源的存档网关是占位实现，未照搬。main 中新增 `autoload/save_gateway.gd` 适配既有 `GlobalState`；原有存档字段仍由 main 状态机序列化，不写 `placeholder_run`。
- 项目配置仅修改 `run/main_scene` 和新增 `SaveGateway` autoload。现有插件、窗口、渲染和其余 autoload 保留。
- 新增 `ui/main_menu/menu_map_entry.gd/.tscn`，继承 main 的 `map_run_demo.gd`；所有地图算法、碰撞、迷雾、关口、节点演示与换层规则仍使用 main。

## 运行与操作

Godot 按 F5 从 `res://ui/main_menu/main_menu.tscn` 启动。

1. 空档案“继续游戏”置灰；“新游戏”调用真实 PRG-002/003 创建一局，进入 main 地图。
2. 有进行中的局时，新游戏先确认覆盖；取消不改变本局，确认通过 main 的弃局方法保留对局历史。
3. 地图中“保存本局”写入当前档案；“保存并返回开始界面”保存成功后返回。有待处理节点时先完成或取消。
4. “继续游戏”保留局身份、地图、楼层、角色位置、探索/节点状态和随机流。未关闭程序时复用内存局；重启后由 main 恢复局与随机快照，地图仅校验同一随机上下文，不重复安装导致既有随机流失效。
5. 右上“当前档案”进入三档选择。切换前先保存当前档；目标校验或索引写盘失败不切换。档案页增加“返回”，可不切换直接回菜单。
6. 删除须确认；文件及其备份移到对应存档目录的 `deleted/`，当前档删除后清除内存局与继续入口。可以手动将归档文件恢复到原路径。
7. 退出先保存；失败时保留窗口并给出提示。初始化读取失败时明确提示，不静默覆盖错误文件。

## 存档与兼容

| 文件 | 作用 |
| --- | --- |
| `user://spotlight_save.json` | 第一档，沿用 main 原路径，不自动迁移或清空旧档 |
| `user://save/slot2.json`、`slot3.json` | 第二、第三档，使用同一 main 存档格式 |
| `user://save/menu_profile.json` | 当前档案索引，不替代 main 的设置/成就数据 |

地图保存为档案顶层可选扩展 `menu_map_checkpoint`，包含 `run_id` 与 `PlanarMapRun` 快照。`GlobalState` 原有 `active_run`、设置、解锁、成就和历史结构保持不变。网关让 main 状态机先写独立中间件，再加入地图扩展，原子安装完整 JSON，原档保留 `.bak`。地图身份/版本/内容与随机快照均在载入前预检；错误扩展不自动重生成地图。

尚未点击继续时，磁盘局与地图扩展也会在保存/切档时保留。旧 main 存档没有地图扩展时仍可继续原 PRG-003 的局，由现有配置初始化地图视图；旧版本未保存的地图位置无法凭空恢复。

新局参数为 `data/config/main_menu_new_run.json`，楼层生成参数继续读 main 的 `data/config/flat_2d/demo_run.json`。默认三张地图、100 生命、0 金币、空初始牌组/奖励池；不自动解锁卡牌或改变 main 卡牌策略。要配置初始卡牌须同时提供合法目录与已解锁 ID，校验仍由 main 执行。
