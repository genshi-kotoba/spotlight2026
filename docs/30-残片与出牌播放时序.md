# 残片与出牌播放时序

## 行为

当前牌产生残片反应时，卡牌动作先在连锁起点停一拍，接着触发格亮起，隔半拍效果格再亮；两格与连锁反馈都播完，才显示本牌下一段普通效果、下一张牌或战斗结束。若需要玩家选择，先完成前序残片展示，再开放选择；提交后沿原队列继续。

战斗逻辑仍由 `BattleEventQueue` 同步执行，当前事件的派生反应先于原续接点处理。此次没有改变伤害、随机数、残片次数、事件预算或存档结构；逻辑致死仍取消后续效果，不会为了动画让已死亡敌人继续承受剩余出牌。

## 展示边界与接口

- `BattleTestScene`按真实信号及事件记录卡牌开始、普通效果、残片、反馈和卡牌结束快照。回放期间生命、回合、手牌、牌堆、银币与残片生效次数读取当前播放快照，避免提前展示逻辑最终值。
- `card_resolved`后的反应也可能触发残片；卡牌结束展示在后续反应收齐后才排入，不以该信号立即结束动画。
- `RelicBookView.flash_cell(index) -> Tween`返回本次闪光；非法索引返回null。闪光与悬停共用同一套高亮，先亮住再按能量淡出。旧调用方可以忽略返回值。战斗展示等候仍有效且运行中的Tween；同格重复闪光覆盖前次，场景退出不等待已取消动画。
- 相邻残片连锁按批闪光，按格等待最后一条Tween，不为每次传播追加固定延迟。亮格提示挂在书页下方，一次激活推一条，逐条往下堆，每条各自计时四秒后淡出退场，后到的提示不顶掉先到的；居中横幅不再使用。
- `relic.activate`运行期metadata中的 `relic_activation_started`标识实际进入动作分支的激活，避免预算跳过的事件误播效果。它不参与随机或存档协议。
- `_presentation_pending()`统一表示仍有待播放事件、闪光、待完成卡牌、飞牌或选择流程。标题、提示、怪物文字停止、领奖和返回地图共同尊重该边界，预测伤害不产生真实终局。
- 正式地图开局准备完毕后允许释放加载遮罩，随后继续播放或等待选择；避免加载器暂停场景树，同时又等绑定场景的Tween完成。

## 验证范围

已做原生复现与修复前后对照：同一卡多段效果、连续多卡、残片后的选择交互、普通卡致死、残片致死、自伤致死、敌方回合致死，检查卡牌／残片真实播放顺序及终局文字门控。交互夹具明确为测试适配，不表示正式残片新增了选择能力。

正式地图另覆盖开局装载残片、转场释放、真实弃牌、两场战斗的领奖与回图、开包重开选择和继续存档。生成／连锁、规则队列和卡牌规则回归保持通过。测试驱动、测试地图、隔离存档和验收应用均留在仓库外，不进入正式游戏内容。
