# 万灵药升级、商店服务与固定地图移速

桌面 main 与独立 Android 工程同步实现。原有触控寻路、二次点击交互、长按悬停、拖动、安全区与独立存档继续保留。

## 局内升级

背包左侧增加两个按钮，正式战斗及结算查看期间不可升级。升级随本局保存；新游戏重新从零开始。

- 每回合牌位 +1：五次价格依次为 2、5、6、9、11 万灵药。以默认 3 牌位计算，最多升到 8；下一场战斗自动使用已升级的基础牌位，残片产生的临时牌位效果继续叠加。
- 解锁典籍格子：点击后以蒙层阻止其他区域交互，只能选择锁格或取消；点击任一锁格会一次扣费并解锁该红框内整组格子，然后退出选择状态。悬停时整组同时高亮。

图片分组（从左上角起，行列均从 1 开始）：

| 分组 | 格子 | 一次性费用 |
| --- | --- | --- |
| 右上 | 第1行第4列、第2行第4列 | 4 万灵药 |
| 右中 | 第3行第4列、第4行第3/4列 | 8 万灵药 |
| 左下 | 第4行第1/2列、第5行第1列 | 8 万灵药 |
| 底部 | 第5行第2/3/4列 | 4 万灵药 |

老存档已经开放的格子保持开放；点击一个仍锁定的格子按该组原价解锁剩余格子。已解锁格子不会重复扣费。余额不足或保存失败均不改变物资和格子。

## 结点万灵药

- 普通、精英、Boss 战斗奖励各包含 2 个万灵药，仍需在奖励弹窗领取。
- 宝箱、残堆的奖励列表额外包含 2 个万灵药，与原物品一起领取。
- 随机事件完成和离开商店时各发放 2 个万灵药；领取标记按地图与结点保存，反复访问不会重复发放。
- 死亡及原有无奖励撤退继续遵守原结算规则。旧版尚未领取的奖励快照仍兼容读取。

## 商店

- 货架、附魔及删牌目标卡面悬停时显示放大预览，预览避开屏幕边界且不截获鼠标输入；手机版沿用长按悬停。
- 下方提供删牌服务：每店三次，依次免费、50 银币、100 银币。选择列表展示真实牌组副本，至少保留一张牌。
- 同一区域提供驱魔：每店一次，300 银币。悬停说明为“驱散典籍残片的负面效果”，目标包括已装备与背包中的负面附着残片。
- 驱魔保留残片主效果、名字与颜色，仅移除负面附着；使用自描述的清洁 ID 持久化，冷恢复与战斗典籍规则引擎均可读取。
- 两种服务都在确认目标时扣费；取消不扣费；保存失败回滚银币、牌组/残片和商店计次。

## 界面与地图

战斗手动弃牌按钮仅显示“弃牌机会 N”，不再显示手牌上限。
地图下方左右两个提示/调试面板及速度滑块已移除。移速倍率固定为 1.5，删除 Shift 与连续行走的额外倍率，保留起步/停步平滑。
