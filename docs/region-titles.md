# 地区首次进入标题

最新四层工程已启用“雾中显字”，主标题与副标题均带深色阴影。

## 正式配置

`data/config/region_titles.json` 的 `enabled` 为 `true`。

| 地图 | 语义地区 ID | 标题 | 副标题 |
| --- | --- | --- | --- |
| world:floor-001 | alchemy_workshop | 炼金工坊 | 地底 |
| world:floor-002 | elbak_slums | 贫民窟 | 埃尔巴克 |
| world:floor-003 | nock_cathedral | 诺克大教堂 | 祷告厅 |
| world:floor-004 | cathedral_summit | 教堂顶端 | 神临 |

地区身份不含随机种子，每个地区在整个存档中只显示一次；重进、读档和新开一局都保留记录。修改文案不重置首次记录。旧存档缺少历史时按尚未显示处理，不根据已经生成的楼层猜测历史。旧三层局保留原来的终点，不会通过本功能扩展成四层局。

地区 ID 使用小写英文字母开头，后接小写字母、数字、点、下划线、冒号或连字符，最多 128 字符；多个地图可以共用一个地区 ID。

## 生命周期与动效

地图载入成功只排队候选。等待真实地图、EncounterFlow 业务绑定及黑场完成，且没有待处理节点、奖励或菜单时才播放。地图替换、退出、转场或弹窗会取消当前标题，不拖延场景切换，不拦鼠标或锁输入。第三层 Boss 的奖励领取完成后才显示第四层标题。

主标题保持整句排版，以 RichTextEffect 从中央向两侧渐显并轻微上移；透明 SubViewport 的整句纹理从模糊变清晰，避免模糊字体图集。默认总长 4.3 秒，包含淡入、停留和淡出，副标题稍后出现，花饰展开。标题阴影复用同一张离屏纹理，向右下偏移并柔化；小字有独立文字阴影。`reduced_motion` 保留整组淡入淡出，关闭逐字位移与模糊。

表现组件 `ui/components/region_title_overlay.gd` 可独立实例化并调用 `play(entry, style)`；业务首次判断由 autoload `RegionTitles` 负责。结束或取消后释放表现节点和离屏纹理。

## 存档与回退

`GlobalStateMachine` 的可选字段 `seen_region_titles` 记录已经显示的语义地区 ID。旧版 v1 缺省为空；没有记录时不增加该字段。首次记录通过现有 SaveGateway 完整存档原子写入，保存失败撤销本次追加并跳过标题，保留以后重试机会。

先成功保存再播放；若恰在保存成功与标题首帧之间崩溃，首次记录仍视为已消费。回退只需设置 `enabled: false`：关闭后不创建 UI、不轮询、不消费记录，也不擦除已有历史。
