# 怪物图鉴数据接入

来源为工作区 `怪物表.xlsx` 的“怪物”工作表，范围 A1:G24。仅接入该工作表，不改同一工作簿中的卡牌、典籍残片、附魔或药水数据，也不修改原始 Excel。

## 字段与编号

23 条记录导入 `data/text/monsters.csv`，保持原有六列表头和图鉴接口。

| Excel 字段 | 图鉴 CSV 字段 | 处理方式 |
| --- | --- | --- |
| 编号 | 编号 | 保留 1–23，自然数字顺序；与图片资产编号不是同一标识 |
| 怪物 | 怪物名 | 原样保留，包括标点和表内写法，不擅自更名 |
| 资产路径 | 怪物图资源路径 | 保留 `res://assets/chr/CHR-003.png` 至 `CHR-025.png` |
| 机制 | 能力文本 | 空白填“暂无” |
| 文本 | 文本 | 空白填“暂无” |
| 级别、出现层数 | 类型与出现地 | 合并为“普通 · 第2层”等展示文本，保留两项信息 |

原表的机制与背景文本尚未填写，因此本次不编造能力、生命值、攻击数值或行动脚本，不改变现有战斗测试怪物及结算规则。后续填写能力文本也不会自动执行自然语言；战斗行为需要另外接入事件队列和规则引擎。

## 界面与进度

从开始界面点击“图鉴”，再点击“怪物”。列表按编号排列，预览显示图片、名称和能力文本，点击打开详情：左侧预览，右侧显示编号、图片路径、怪物名、能力文本、类型与出现地、文本及当前解锁状态。属性区可滚动，详情可用按钮或 Esc 关闭。

三种显示模式继续支持“显示所有 / 显示已解锁 / 显示未解锁”。未解锁条目在所有或未解锁模式下仍可查看详情，不新增信息遮罩。

解锁状态不写入 Excel 或 CSV，不因导入或重载而重置；继续使用每个档案的 `GlobalState.unlocked_monsters`。本次不自动解锁所有怪物，也不定义“遇到即解锁”或“击杀才解锁”的新规则。既有接口示例：

```gdscript
var monster := TextCatalog.entry("monsters", "23")
var error := TextCatalog.unlock_entry("monsters", "23")
# 23 为图鉴编号；对应图片 CHR-025，不要用 "CHR-025" 替代表内编号。
```
