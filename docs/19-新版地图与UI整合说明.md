# 新版 map-2d 与 PRG-017/018 UI 整合

日期：2026-10-19。目标工程：`spotlight2026-main`。

## 整合范围

- 地图来源：同级目录 `spotlight2026-map-2d`。
- UI 来源：同级目录 `spotlight2026-prg-017-018-ui`。
- 两个来源均为工程交付副本，因此按模块、函数和资源整合，不进行 Git 历史合并。
- 保留目标工程原来的 Git 分支和未提交修改，没有提交或推送 GitHub。

## 地图

正式入口仍为 `ui/main_menu/menu_map_entry.tscn`。新的继承链为：

`menu_map_entry.gd → map_exploration.gd → map_run_demo.gd → map_demo.gd`

接入新版地图生成器、空间细化、高度配方、2.5D 高低差、角色表现、遮挡、雾、光照及环境资源。旧的 F6 地图入口仍转入同一正式业务装配层。

新增 `MapPresentation` 自动加载节点，只缓存当前层的显示资源。进入战斗时隐藏并暂停地图显示，返回时复用缓存；局内进度、怪物分配、战斗、奖励、商店和存档仍由 main 原系统负责。高度与环境使用独立随机地址，不接管战斗随机流。

新版地图需要异步准备显示。`load_map()` 成功表示逻辑已接受，`is_map_ready()` 才表示显示和缓存已就绪；准备期间不允许移动或节点交互，界面显示准备进度。测试统一等待此接口，不再用固定数帧猜测加载时间。

旧地图检查点继续恢复原布局、已分配怪物、探索和完成状态，不因为整合而重新生成地图。新局及尚未生成的楼层使用新版生成配置。

## UI 与 main 规则的冲突处理

采用新版战斗背景、布局、血条、格挡盾、Buff 图标、命中反馈、结算指针动画、大卡预览、背包立绘及通用暗金主题。

保留以下 main 行为，不使用 UI 副本中的旧玩法实现：

- 正式卡牌、按类型及稀有度换底图、CSV 文本和图鉴属性。
- 战斗状态机、事件队列、规则引擎、交互弃牌、弃牌堆选牌、指针移动和循环保护。
- 锁牌、空牌位、不占牌位的卡、动态出牌上限；结算展示跟随 main 的出牌区快照。
- 新局八张初始牌、空典籍、种子怪物分配、三层 Boss 推进及第四层待开放状态。
- 奖励领取、卡包与残片包、一次刷新、残片安装、永久卡牌副本及附魔。
- 真实银币和万灵药；万灵药读取 `run.inventory_state.elixir`。
- 自然首抽和每回合抽牌不触发“获得卡牌”残片，效果抽牌仍可触发。
- 怪物图鉴 CSV、独立战斗 TXT，以及此前调整好的漂浮文本节奏、字号、左右分布和近期避重逻辑。
- 原有保存失败回滚、未结束战斗冷恢复和存档检查。

典籍始终为 **4 列 × 3 行，共 12 格**，未采用 UI 副本的 20 格规则。手牌使用新版尺寸，出牌区卡面继续为手牌的 **1/2**；超过十个牌位后保持单列纵向滚动，不在屏幕右侧再开一列。

新版背包与战斗 HUD 读取真实局内物品；不注入 UI 副本的假金币、假药水或旧测试牌组。`data/text/items.csv` 仅为展示元数据，不会自动给新局发放物品或执行其说明文本。

## 接线与生命周期修复

- 地图战斗的意图数字改接新版 `IntentValue` 节点，避免旧 `IntentBadge/Value` 路径使开局停在 IDLE。
- 两类战斗入口都连接原状态机的受伤、治疗、格挡事实信号，反馈层不再另算一次效果。
- 手选序列可点击、取消和拖动重排；锁定原牌位与空牌位不被拖拽越权修改。
- 结算期间保留 main 的出牌区快照；交互弃牌/选牌继续暂停并恢复同一个事件队列。
- 模态层阻断底层拖动；战斗菜单高于手牌与牌堆预览，附魔提示不会残留在菜单上方。
- 离场后的延迟滚动和刷新不再访问已退出场景树的控件。
- 血条补间从当前显示值开始，重复快照不打断同目标动画。
