# 奖励选择动画与悬置

普通卡牌包、稀有卡牌包、典籍残片包改为全屏选择层，不再把候选项放在静态弹窗内。附魔书的两级选牌和商店保持原流程，战斗胜利的领取奖励窗口也不变。

## 表现

- 所有候选项从画面中央以正常大小的 16% 同时飞散，飞行约 0.16 秒；落位后使用阻尼弹簧同时放大，约 0.42 秒开放点击。
- 悬停放大至 1.35 倍，其他选项根据放大后的实际宽度让位；位置与缩放保持连续速度，不因每次悬停重新创建 Tween。弹簧以最大 1/120 秒子步积分，避免低帧率导致数值发散。
- 卡牌复用 CardView，残片复用现有拼片模板、颜色与富文本说明；直接点击卡面或残片即可选择。
- 候选区根据可用宽高等比适配，为悬停留足空间。灰暗背景仅作为模态遮罩，不修改背包、立绘或卡面本身的颜色。

## 悬置和交互边界

选择层中央偏下为“悬置”按钮。点击后候选项缩小、回收到中央并淡出，额外遮罩在 0.16 秒内消失，按钮改为“恢复选择”。再次点击会重新展开同一组候选项，不刷新、不取消、不消耗包。

选择尚未完成期间，底层背包不能关闭、切页、使用物品、打开另一个包或修改典籍。悬置后仍可滚动牌组、点击牌组卡牌查看大图、悬停查看背包与典籍中的残片说明和作用范围。Esc 在大图打开时只关闭大图，否则切换悬置；场景快捷键不会穿透。恢复选择会收起残留的大图与提示层。

原有刷新规则保留：普通卡牌包和残片包各刷新一次，稀有卡牌包不能刷新；悬置期间不提供刷新入口。刷新后重新播放展开动画。保存失败保留当前选择，并显示错误；仅成功提交 RunRewards.choose 后才消耗包并解除背包只读锁。

锁定状态属于 UI，不写入存档。候选项及刷新次数仍由 RunRewards 持久化，重新加载后不会重抽；不引入永久锁死存档的标记，也不让动画推进任何战斗或奖励规则。
