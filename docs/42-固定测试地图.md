# 固定测试地图

在项目根目录运行：

```sh
godot --path . res://ui/testing/fixed_test_menu.tscn -- --fixed-test-map
```

`godot` 可替换为本机 Godot 可执行文件路径。打开后可新建或继续固定测试档；新建会重新生成初始背包。

- 四区可直接切换：炼金工坊、贫民窟、教堂、方舟。
- 固定44个节点：23种主怪各有一个对应节点、全部12种炼金事件，以及前三区各一处商店、宝箱和残堆。
- 地形、坐标、节点内容和战斗阵容固定。Boss单怪；普通和精英节点使用固定二怪/三怪阵容，召唤仍遵循三怪上限。
- 金币、万灵药显示∞；支付不扣金币，余额相关效果统一按1000金币计算。
- 每次新建背包：10个随机组合残片、5瓶药水（四种各一瓶，再随机一瓶）、2个普通卡包、1个稀有卡包。继续测试不重抽背包。
- 首回合抽6张，后续每回合2张。牌组及其他战斗机制沿用当前实现。
- 区域不受Boss通关门槛限制，打败Boss留在本区；切换前需完成当前节点及领奖。

操作：WASD移动，E交互，Tab背包，M地图传送。右下可按名字选择本区节点并传送到门前，之后按E进入。点击“测试菜单”返回独立菜单，新建可重置本轮全部进度。

源码入口：ui/testing/fixed_test_menu.tscn。命令行必须带 `-- --fixed-test-map`，它启用独立档案与测试场景路由。测试档保存于 `user://fixed-test-map/game.json`，与普通档分离。交付时的专用运行副本另设用户目录 SpotlightFixedTestMap20261020。

战斗机制与整体体验由用户验收。事件重进、对象预览和按钮反馈已做针对性回归；不代表全部战斗完成验收。macOS 缺少 Wwise 原生动态库的环境会保留音频不可用提示。
