# 战斗线交接与合并说明

本线负责战斗界面的表现层：手感、敌人目标指示、典籍触发表现。战斗逻辑、随机、存档结构未改动。

## 合并状态

`feel/nonbattle`（跑图线）已合并进 main，commit `c451ea9`。本文档描述的改动在其之上，两条线当前不再分叉。公共组件（缓动时长、按压手感、节拍闸门）按「谁先落地谁定标准」合并，未出现两套标准。

## 分工边界

- 卡组与初始牌组的数据接入属他人。本线只保证通道可用：他人填好 `data/config/main_menu_new_run.json` 的 `initial_deck` 与 `card_catalog` 后，新局能正常开起。
- 音效模块属他人完成，本线未触碰。
- 跑图（非战斗）触点在 `feel/nonbattle` 线完成，与本线无重叠文件。

## 接口契约

- `unique_name_in_owner` 的 17 个节点名是接口契约，不得改名。
- `EnemyRack.refresh(enemies: Array, target_id: String)`：槽位数量变化时才重建槽，数量不变时原地更新。
- `EnemyRack.slot_selected(enemy_id: String)`：点击战场上的敌人时发出。
- `RelicBookView.flash_cell(index) -> Tween`：返回本次触发高亮，非法索引返回 null。
- 战斗表现只在父场景 `battle_test_scene.gd` 改，生产入口继承后自动生效。

## 调参位置

布局常量在 `ui/battle/battle_test_scene.gd` 顶部。节奏参数走 `@export`，可在检查器里调：

- `resolution_delay` / `pointer_only_delay` / `enemy_turn_delay`：单拍名义时长
- `resolution_budget` / `resolution_speedup_after` / `resolution_max_speed`：结算总预算、起提速的指针格数、提速上限
- `test_enemy_count`：测试局同屏敌人数

典籍节拍为 `RELIC_CHAIN_PAUSE`（0.25s，连锁起点停一拍）、`RELIC_STEP_BEAT`（0.3s，触发格与效果格之间）、`relic_hint_stack.gd` 的 `LIFETIME`（4s，提示驻留）。

## 启动方式

- 战斗测试场景：编辑器打开 `ui/battle/battle_test_scene.tscn` 后按 F6。不改 `project.godot` 的 `run/main_scene`（当前为 `ui/main_menu/main_menu.tscn`）。
- 正式战斗入口：`ui/battle/map_battle_scene.tscn`。
- `ui/dev/` 放本地调试场景，未纳入版本控制。
