# 血条与卡牌移动动画

## 血条回跳修复

战斗规则队列同步执行，界面按结算指针异步播放各张卡牌的快照。原先 `_refresh_zones()` 每次刷新都从状态机读取整轮结算后的最终血量，随后指针又显示中间快照。发生致死伤害时，表现为血条先归零、再恢复中间血量，反复回跳。

现在在提交序列前保存当前战斗画面，结算期间的普通刷新只使用当前播放快照。指针推进时显式更新播放快照，进入怪物回合后再同步最新权威状态；不改变规则队列、伤害计算或存档。

血条每次从当前显示比例平滑过渡到新比例，窗口固定为 **0.3 秒**，采用 cubic ease-out。连续变化会取消旧补间并从当前显示值接续；同目标刷新不重启动画，也不会在 Tween 尚未启动时直接跳到目标。玩家/怪物血条、受伤/治疗共用此逻辑。

## 飞牌

复用现有 CardView 创建只用于表现的临时卡面，位于战斗 UI 上层、弹窗下层，且不接收鼠标输入。卡牌实例 ID 用于绑定飞牌与真实卡牌，不复制或修改玩法牌组。

| 阶段 | 时长 | 行为 |
| --- | --- | --- |
| 起飞 | 0.07 秒 | 从当前扇形/悬停姿态缩小并转正 |
| 飞行 | 0.18 秒 | 保持 0.09 倍比例，平滑移动到目标 |
| 落位 | 0.09 秒 | 出牌区放大到目标卡面比例；弃牌堆继续缩小并淡出 |

出牌列布局和自动滚动稳定后启动动画；飞行期间逐帧读取目标，支持插牌、滚动与界面重建。到达前隐藏目标真实卡面，完成后无缝恢复并销毁临时节点。快速取消或取回卡牌会清理该实例的飞牌。

交互弃牌在逐张选中时立即播放，不必等全部选齐。普通弃牌监听状态机原有 `card_discarded` 信号；整列结算后的入弃动画延后至指针播放完毕，锁牌不入弃。出牌入弃播放完成后继续怪物回合，不延迟或重排逻辑事件队列。

## 验证

新增 `tests/battle_animation_selftest.tscn`，覆盖血条 0.3 秒窗口、相同目标重复刷新、连续扣血接续、治疗、真实致死序列的单调血条、飞行分段、目标滚动/插牌、快速取消、多选弃牌、正常出牌入弃以及玩法随机流不变。

新增动画自测、手牌输入、正式卡牌交互/锁牌、新版 UI、战斗奖励、事件队列、卡牌战斗整合、效果规则与怪物漂浮文本，共 9 组回归通过。动画自测在图形模式下同样通过，并检查落位与弃牌截图。日志、隔离存档与截图位于忽略目录 `.godot/`，不覆盖玩家存档。
