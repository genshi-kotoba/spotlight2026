# 12 · 战斗与探索界面交付说明

本分支同时交付两块界面：**战斗界面**（PRG-017）与**探索界面**（地图 + 冒险菜单，PRG-018 方向）。两者共用左上状态列与冒险菜单，改一处两边生效。战斗规则、状态机、事件队列、规则引擎、卡面逻辑一行未改；15 个 `unique_name_in_owner` 节点名全部保留。

### 手牌交互（照 `reference/card-and-dice` 的 HandUIController）

- 悬停放大：绕卡面底边中点放大 1.5 倍（放大 0.01 秒、回正 0.18 秒）。
- 扇开：以悬停卡为中心，左右按距离 1/2/3 分别外移 50 / 35 / 15 px，再乘按张数取的系数（默认 0.6，可在检查器调）；进 0.15 秒、回 0.18 秒。
- 换卡不塌扇：离开与进入事件延后一拍统一判定，并杀掉上一条扇开补间。
- 参数全部在检查器：`hand_hover_multiplier`、`hand_hover_duration`、`hand_hover_return_duration`、`fan_offset_long/medium/short`、`fan_duration_in/out`、`fan_factor_by_count`。

## 二、探索界面（地图 + 冒险菜单）

### 一句话

地图界面复用战斗的左上状态列；点头像（或按快捷键）打开冒险菜单，内含地图 / 背包 / 设置三页。地图页是**只查看**的真实地图渲染，可缩放平移但不移动角色，供跑图与战斗中规划路线。

### 冒险菜单

- 打开：点左上头像、点右上小地图（直接进地图页），或快捷键。
- 三页：
  - **地图**：`MapViewer`，缩放 0.55×–2.6×、拖动平移、主角青点标记；地图界面喂会话的已探索视图（与小地图同源，每次打开刷新），战斗里没有会话则按「全图已知」喂。
  - **背包**：典籍 20 格 / 卡组真卡面（6 列，可滚动）/ 背包 5×4 共 20 格；三个标题都带真实计数。
  - **设置**：音乐 / 音效滑条写入 `GlobalState.settings` 的 `music_volume` / `sfx_volume`；放弃本局、退回主菜单、退出游戏；内容居中。
- 放弃本局：二次确认就在设置面板内联动——「放弃本局」原位换成「确认放弃 / 取消」，不确认不清档。
- 快捷键：Esc 打开设置、Tab 打开背包、M 打开地图；在对应页再按一次即退出，Esc 在任意页都能退出。地图原本用 Tab「切换目标」的键让给背包，改绑 Q。`menu_map`(M) 动作由 `RunMenuOverlay.ensure_menu_actions()` 注册。
- 键盘锁：菜单打开时外层地图进入暂停，键盘移动、鼠标转向、滚轮缩放、E 交互一起锁住；关闭后还原（并保留打开前是否已暂停）。

## 三、怎么跑

- 主菜单起：`run/main_scene` 是 `ui/main_menu/main_menu.tscn`；「开始游戏」进跑图落点 `ui/main_menu/menu_map_entry.tscn`。
- 战斗界面：直接打开 `ui/battle/battle_test_scene.tscn` 按 F6，或从典籍页面的「战斗」按钮进。
- 测试牌 `测试·选择弃牌` 会要求再从手牌点 2 张弃掉才会继续，提示条上一直写着。

## 四、自测

- 四个场景（跑图落点 / 主菜单 / 战斗 / 纯地图）启动无报错、无泄漏。
- `tests/relic_ui_selftest.tscn`：9 项全通过。
- 界面交互由临时脚本核实（不入库）：悬停卡面可见比例 1.00、扇开左右各 30 px 且换卡不塌、拖动可翻手牌、地图查看器缩放 / 拖动改相机、菜单内滚轮不动外层地图（关闭后恢复）、点小地图进地图页、Tab/M/Esc 的进出、设置在面板内二次确认、战斗点头像开同一套菜单。

## 五、遗留

- 缺素材处仍是色块占位：CHR-002、UI-004、UI-014、UI-015、UI-016、UI-020、UI-021、UI-006。
- 伤害预测只留了 1782,16 → 72×140 的范围框，形式与内容待定。
- 背景压暗是平涂，径向暗角等 ENV-001 正式图或用着色器。
- 多敌人站位本轮不做。
- 冒险菜单的卡组要显示真卡面，需要跑图开局时带 `deck`（`RunStateMachine.start` 读 `prepared["deck"]`），目前跑图配置里没有初始卡组。
- 设置页音量只写入设置，工程里还没有音频总线接入。
