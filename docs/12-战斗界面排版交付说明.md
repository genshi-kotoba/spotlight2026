### 战斗交互（照《杀戮尖塔》）

| 操作 | 行为 |
| --- | --- |
| 点手牌 | 选中/取消，进入出牌队列 |
| 拖手牌到出牌区 | 按落点插入队列（两列各 5 格，按 x 判列、y 判行），插入点之后的牌上移一格再滑回 |
| 点出牌区的牌 | 拿回手牌 |
| 点抽牌堆/弃牌堆 | 打开牌堆弹窗 |
| 牌堆弹窗里点卡 | 居中 0.7 倍大图，点任意处关闭 |
| 背包卡组里点卡 | 居中 0.62 倍大图 |
| 结算 | 指针（弯箭头）依次指向正在结算的牌，出牌列左侧同步放大那张牌 |

### 手牌交互（照 `reference/card-and-dice` 的 HandUIController）

- 悬停放大：绕卡面底边中点放大 1.5 倍（放大 0.01 秒、回正 0.18 秒）。
- 扇开：以悬停卡为中心，左右按距离 1/2/3 分别外移 50 / 35 / 15 px，再乘按张数取的系数（默认 0.6，可在检查器调）；进 0.15 秒、回 0.18 秒。
- 换卡不塌扇：离开与进入事件延后一拍统一判定，并杀掉上一条扇开补间。
- 参数全部在检查器：`hand_hover_multiplier`、`hand_hover_duration`、`hand_hover_return_duration`、`fan_offset_long/medium/short`、`fan_duration_in/out`、`fan_factor_by_count`。

## 二、探索界面（地图 + 冒险菜单）

### 冒险菜单

- 打开：点左上头像进背包页、点右上齿轮进设置页、点右上小地图进地图页；战斗界面没有小地图，地图页仍可用 M 打开。分页按钮已删除，浮层标题随页切换。三页：
  - **地图**：`MapViewer`，缩放 0.55×–2.6×、拖动平移、主角青点标记；地图界面喂会话的已探索视图（与小地图同源，每次打开刷新），战斗里没有会话则按「全图已知」喂。
  - **背包**：浮层 1760×980（80,50）；三列——左列立绘（CHR-001 正身，440×940，从面板左/上/下越出出血）/ 中列上典籍、下背包（典籍 4×5 居中，96×96 格，UI-020 纸片拼回整张手写纸，格内 21px 残片名；背包 7 列 × 3 行共 21 格，78px 格，12px 物品名，格子垫深色底板，一屏全见不滚动）/ 右列卡组 5×3 可见（738 宽，卡宽 140、高 240，垂直滚动，卡面自带 18px 卡名与 14~13px 描述）。标题只留真实计数：`背包 N / 21`、`典籍 N/20`、`卡组 N`。
  - **牌堆查看**：点抽牌堆/弃牌堆打开大卡网格，5 列、卡宽 192、卡高 327，卡面自带 22px 卡名与 16~14px 描述（自适应到全文装下）；Esc、点关闭或点遮罩都能退出。
  - **可出牌提示**：手牌在不可出牌（结算中、弃牌等待、战斗结束）时整张压暗，可出牌时恢复原亮度；悬停放大与扇开保持原规则。
  - **设置**：音乐 / 音效滑条写入 `GlobalState.settings` 的 `music_volume` / `sfx_volume`；放弃本局、退回主菜单、退出游戏；内容在 860 高的内容区里垂直居中（滑条 y=344/408、按钮 y=538/610/682）。
- 新局初始牌组由 `data/config/main_menu_new_run.json` 的 `initial_deck` 提供，当前为 8 种各 2 份共 16 张：`bonk` / `duck` / `feeling_good` / `nudge_back` / `one_shot` / `oops` / `peek` / `spit`。初始牌组只作为本局预置，写进 `run_unlocks` 供本局使用，不写回已保存的解锁表。
- 放弃本局：二次确认就在设置面板内联动——「放弃本局」原位换成「确认放弃 / 取消」，不确认不清档。
- 快捷键：Esc 打开设置、Tab 打开背包、M 打开地图；在对应页再按一次即退出，Esc 在任意页都能退出。地图原本用 Tab「切换目标」的键让给背包，改绑 Q。`menu_map`(M) 动作由 `RunMenuOverlay.ensure_menu_actions()` 注册。
- 键盘锁：菜单打开时外层地图进入暂停，键盘移动、鼠标转向、滚轮缩放、E 交互一起锁住；关闭后还原（并保留打开前是否已暂停）。

## 三、怎么跑

- 主菜单起：`run/main_scene` 是 `ui/main_menu/main_menu.tscn`；「开始游戏」进跑图落点 `ui/main_menu/menu_map_entry.tscn`。
- 战斗界面：直接打开 `ui/battle/battle_test_scene.tscn` 按 F6，或从典籍页面的「战斗」按钮进。
- 测试牌 `测试·选择弃牌` 会要求再从手牌点 2 张弃掉才会继续，提示条上一直写着。

- 伤害预测已删除；银币数量改读跑图金币。
