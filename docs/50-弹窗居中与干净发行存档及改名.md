## 覆盖确认框

`ui/main_menu/confirm_dialog.gd/.tscn` 显式安装全屏根节点与遮罩布局，面板使用中心锚点，显示和尺寸变化时重新计算中心；主菜单中的弹窗实例显式启用锚点布局。避免源场景缺省 layout_mode 在导出后成为左上角定位。保持原确认、取消信号和遮罩拦截，不改变覆盖存档规则。

新增 `tests/confirm_dialog_layout_selftest.gd/.tscn`，两端检查 1920×1080、1280×720、2560×1080 下的面板中心及全屏遮罩。实际 Windows Release EXE 检查覆盖确认并截图核对。

## 无测试数据的发行版

已核查旧 PCK 中没有 `game.json`、旧槽位或测试记录。根因是旧 PC 工程与导出版使用同一本机用户目录与默认存档路径。

`GlobalStateMachine.default_save_path()` 现在区分：

- 编辑器：`user://save/game.json`，保留旧测试数据。
- 导出运行时（包括 Debug/Release）：`user://player/save/game.json`，作为稳定的玩家路径。
- 显式固定地图沙盒仍沿用其专有路径，不影响普通发行版。

GlobalState 和 SaveGateway 初始化使用同一选择；发行版不再自动迁移旧编辑器或三槽位数据。不会在每次启动、每次导出时清空玩家存档。旧编辑器文件原样保留；本轮没有删除真实玩家文件。

两端导出排除列表补充存档目录、旧存档文件、备份和临时文件。测试包与夹具均在 `_local/clean-release-20261021`，不进入交付包。
