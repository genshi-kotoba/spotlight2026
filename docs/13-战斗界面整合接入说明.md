# 战斗界面与卡面 UI 接入说明

面向整合：这份文档说明界面层现在具备什么、隔壁怎么接、以及不满意时改哪里。

## 一、交付范围

主场景已经是战斗界面：`project.godot` 的 `run/main_scene` 指向 `ui/battle/battle_test_scene.tscn`，跑起来就是完整战斗。

| 界面 | 场景/脚本 | 状态 |
| --- | --- | --- |
| 战斗主界面 | `ui/battle/battle_test_scene.tscn` + `.gd` | 可用，含血条、状态栏、手牌扇形、出牌区、牌堆、结算与取消、伤害预测、典籍、背包 |
| 卡面 | `ui/components/card/card_view.tscn` + `ui/components/card/` | 可用，卡面按数据驱动，插画为占位 |
| 主菜单 | `ui/main_menu/main_menu.tscn` | 可用，存档槽、继续、设置 |
| 世界地图 | `ui/world_map/flat_2d/` 与 `map_viewer.gd` | 可用，读 `data/config/flat_2d/demo_map.json` |
| 图鉴 | `ui/catalog/encyclopedia.tscn`、`achievements.tscn` | 可用 |
| 典籍测试台 | `ui/relics/relic_test_scene.tscn` | 可用，独立调试用 |

## 二、接法

战斗界面是自包含场景，挂进流程只需要实例化它，不要求改它内部：

```gdscript
var battle := preload("res://ui/battle/battle_test_scene.tscn").instantiate()
add_child(battle)
```

依赖的全局单例（`project.godot` 已注册，隔壁工程也要有）：

```
SeedService   res://autoload/seed_service.gd
GlobalState   res://state_machines/global/global_state_machine.gd
MapEvents     res://core/signals/map_events.gd
SaveGateway   res://autoload/save_gateway.gd
TextCatalog   res://systems/text/text_catalog.gd
```

数据入口：

- 卡牌：`data/cards/**/*.tres`，`CardData` 资源，`effects` 是 `Array[GameEffect]`。
- 典籍残片：`data/relics/`，当前是 `test_fragments.csv`。
- 地图：`data/config/flat_2d/demo_map.json`。
- 文本：`systems/text/text_catalog.gd` 统一取，文案不写死在界面代码里。

## 三、可以改的地方

### 布局与尺寸

全部集中在 `ui/battle/battle_test_scene.gd` 顶部的常量，改常量即可，不用碰逻辑：

| 常量 | 现在 | 作用 |
| --- | --- | --- |
| `HAND_CARD_SCALE` | `0.285` | 手牌缩放 |
| `PLAY_CARD_SCALE` | `0.19` | 出牌区缩放 |
| `HAND_MAX_WIDTH` | `880.0` | 手牌区总宽，决定几张牌开始叠压 |
| `HAND_ARC_SPREAD` | `0.045` | 扇形张开角度，每张牌的角度步长 |
| `HAND_ARC_RADIUS` | `900.0` | 扇形下沉弧度 |
| `HAND_SLOT_COUNT` | `10` | 手牌上限 |
| `PLAY_ROWS_PER_COLUMN` | `10` | 出牌区一列最多几张 |
| `PLAY_STEP` | `110.0` | 出牌区纵向叠放间距 |
| `PLAY_POINTER_W` | `62.0` | 指针列宽，卡牌实际画在 `PlayScroll.left + 62` |
| `PLAYER_BAR_LEFT` / `PLAYER_BAR_WIDTH` | `144` / `250` | 我方血条填充区，必须与 `assets/ui/UI-015` 边框镂空一致 |
| `ENEMY_BAR_LEFT` / `ENEMY_BAR_WIDTH` | `89.5` / `726.5` | 敌方血条填充区，同上 |
| `RELIC_BOOK_POSITION` | `(322,132)` | 典籍位置 |

节点级位置（血条、盾、意图角标、牌堆、结算按钮、预测块）在 `.tscn` 里，用 `offset_*` 直接调。

### 动效时长

- 手牌悬停：`hand_hover_duration`、`hand_hover_return_duration`、`hand_hover_multiplier`，均为导出变量，可在 Inspector 调。
- 受击抖动：`ui/battle/combat_feedback.gd` 的 `_shake()`，振幅 7 → -6 → 4.5 → -3 → 0，每步 55ms。
- 伤害飘字与特效：`ui/battle/vfx_playback.gd`。

### 数值与文案

- 卡牌数值：`data/cards/**/*.tres` 里各 `CardEffect*` 的 `@export` 字段。
- buff 数值：`data/buffs/`。
- 界面文案：走 `TextCatalog`，不写死。

### 配色

- 银币与万灵药数字：`Color(0.909804, 0.705882, 0.333333, 1)`，在 `battle_test_scene.tscn` 对应 Label 的 `theme_override_colors/font_color`。
- 血条填充色、敌方红色：`ui/battle/*.gd` 里的 `HealthFill` 绘制色。

## 四、已知限制

1. 卡面插画是白色占位，等美术出图后替换 `assets/card/card-XXX.png` 即可，代码不用改。
2. 伤害预测只累计卡面伤害与格挡（含力量、虚弱、坚韧），不跑完整结算队列，中毒、护盾消耗、卡牌联动不计入。
3. 战斗中典籍是静态展示，斜书页透视与触发点亮未做。
4. 测试卡仍留在 `data/cards/test/`，真卡接入后可以整目录删除。
5. `DEBUG_ENEMY_BLOCK` 给怪物补了常驻格挡方便看盾，整合前改成 0。
