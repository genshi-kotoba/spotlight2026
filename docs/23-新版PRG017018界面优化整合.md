# 新版 PRG-017/018 界面优化整合

日期：2026-10-19。目标：`spotlight2026-main`。

来源为同级 `spotlight2026-prg-017-018-ui` 交付副本，本次按组件、资源及界面函数整合，未替换 main 的业务系统，未提交或推送 GitHub。

## 接入内容

- 战斗：新版超长怪物血条、按普通/精英/BOSS 换框、意图角标、格挡盾位置、牌堆与操作按钮布局。
- 手牌：扇形排列，悬停转正及 1.5 倍放大，相邻牌按扇形系数自适应让位。悬停放大为 0.06 秒短过渡；点手牌瞬时落位出牌区，不播放飞牌。
- 出牌区：悬停大图、拖动时显示插入位置上方卡牌、拖出整行虚影。预览按实际显示行读取，兼容保留牌与空牌位。
- 典籍：书页透视四边形、逐格悬停说明、触发扩散光环。快照刷新不再擦除正在播放的光效。
- 背包：残片拖入典籍、格间互换、拖回背包、右键或 Shift 点击卸下；原有“点击残片后点击格子”方式仍可使用。
- 背包物品区补齐一屏 21 个槽位；超过 21 件仍显示并滚动，不引入背包容量限制或测试物品。
- 受击采用单次衰减震动，连续命中会中止旧补间并恢复同一基准位置，避免两套震动叠加或立绘漂移。
- 卡面采用新版效果文本区域与默认标题字号，保留正式数据、四类颜色和稀有底图。

新增的五张图片为意图角标、超长血条底图，以及普通、精英、BOSS 三种超长血条框。未用 UI 副本的测试背景或测试怪物覆盖正式资源。

## main 优先的冲突处理

典籍保持 **4 列 × 3 行，共 12 格**。书页底图中的额外两行只是装饰，没有新增逻辑格。出牌区卡面仍为手牌的 **1/2**，超过十张仍单列纵向滚动。

残片背包读取真实 `run.items`，通过 `item_id` 区分同名副本。装入、替换、卸下走原 `RunRewards`；新增 `move_fragment()` 只交换已装格，同样使用保存失败回滚事务，不复制被交换残片。战斗中禁止装配、卸下及开包，仅可查看。地图典籍 HUD 在装配成功后刷新。

下列内容继续使用 main：

- 正式卡牌、CSV 文本、按类型换底图、永久副本及附魔。
- 战斗状态机、事件队列、规则引擎、Buff、交互弃牌、弃牌堆选牌、锁牌、空位、不占槽卡、动态出牌上限、指针和循环保护。
- 新局八张初始牌、空典籍、真实银币和万灵药、种子地图与怪物、奖励与商店、冷恢复存档。
- 加载遮罩、场景预加载、分层战斗背景。
- 漂浮文本回退后的版本：问号/感叹号/句号（全半角）加换行断句、分号加换行形成句内换行、随机字号 200–240、整句自适应缩放。此次未修改漂浮文本脚本。

## 数值参考的边界

新版原伤害预览只识别旧测试攻击/格挡资源。接入 main 后，额外识别正式 `CardEffectProgram` 的固定伤害、格挡与固定次数重复，以及当前力量、虚弱、坚韧、两种附魔。

界面标注为“基础伤害参考 / 基础格挡参考”，不是完整结算模拟。不计易伤消耗、条件数值、指针跳转、残片及后续状态联动，不显示确定击杀结论。预览不发布事件、不改战斗快照、不消耗种子随机流；最终结果只由原事件队列决定。

## 验证

Godot 4.7.2。25 个场景自测及 4 个脚本自测，共 29 组断言通过：

| 战斗与规则 | battle_effect_rules、battle_event_engine、card_battle_integration、state_machine |
| 卡牌与输入 | battle_hand_input、formal_card_ui、formal_cards、card_type_face、card_view、card_effect |
| 典籍、背包、交易 | relic_ui、relic_system、battle_rewards、shop_enchantments |
| 地图与流程 | map、planar_map、map_entry_input、map_relic_entry、world_encounters、main_menu_integration |
| 展示与转场 | monster_catalog、text_catalog、monster_battle_text、battle_environment、scene_transition、scene_preload |
| 界面整合 | prg017018_ui_integration、map_ui_merge、ui_optimization_merge |

新增 `ui_optimization_merge_selftest` 覆盖真实鼠标残片拖拽、同名副本识别、换位、卸下、点击装配、保存失败回滚、越界、超一屏库存、战斗编辑门禁、透视格说明、光效刷新、只读数值参考、大图预览和连续受击复位。

以 1280×720 图形模式运行新增自测、真实地图→战斗整合、主菜单与预加载测试，均通过。检查了背包、扇形手牌、悬停放大、正式节点敌人与资源数量。兼容渲染器会报告既有的“不支持 2D MSAA”提示。

部分无窗口用例会打印 Godot dummy 渲染器的纹理初始化诊断，对应主菜单与预加载用例在图形模式下无此错误。负向测试也会主动输出缺图、非法快照、无目标等拒绝错误。全部测试断言通过，最终编辑器导入及运行测试无脚本解析或运行异常。

日志、隔离存档与截图位于忽略目录 `.godot/`，不覆盖玩家存档。整合前的 UI 与测试备份位于 `.godot/integration-before-ui-20261019/`。
